## 1. 요약

| 항목 | 제안 |
|---|---|
| 알파벳 | 26글자 전체 (축소 알파벳은 쓰지 않음) |
| 로터 | 실물 두 대는 3로터만. 4로터(M4)는 FPGA 전시물과 화면에서만 |

| 공통부 | 메뉴 배선 패널 + 대각선 보드 + 테스트 레지스터를 한 벌 만들고, 기어식 뱅크와 릴레이식 뱅크가 같은 26선 잭 규격으로 붙는다 |
| 시험 전압 | 24 V DC (노출부 전체가 극저전압) |

| 정지 판정 | 릴레이 26개(눈에 보이는 감지 릴레이)가 한다. 전자 장치는 감시·대조·표시만 한다 |

## 2. 규모 결정

### 2.1 26글자 전체

- 세 기계에 **같은 메뉴 카드**를 걸어 같은 정지를 보여 주는 것이 전시의 핵심이다(`docs/PLAN.md` 1절). 소프트웨어 코어·RTL·검증 벡터는 모두 26글자 에니그마 기준이므로, 알파벳을 줄이면 기준 모델을 새로 만들어야 하고 실제 에니그마 전문을 쓸 수 없게 된다.
- 비용을 줄이는 손잡이는 알파벳이 아니라 **스크램블러 수**와 **탐색 범위**(2.3절, 5절)로 둔다.

### 2.2 3로터만 (실물)

- 4로터는 위치 수가 26배(456,976)다. 영국 봄베 속도(약 28위치/초, 5.1절)로 4.5시간이 걸려 실습이 되지 않는다.
- 4번째 로터는 구간 안에서 움직이지 않으므로 "반사판 26종 중 하나를 고르는 선택기"로 볼 수 있다 [@cryptomuseum-bombe]. 실물에서는 반사판 배선판(플러그/카드)을 바꿔 끼우는 것으로 M4의 한 경우를 흉내 낼 수 있으나, 전시 가치에 비해 설명이 복잡하다. M4 해독은 FPGA 전시물(1,344 로터 순서 전체 탐색)이 맡는다.

### 2.3 스크램블러 수: 메뉴 크기와 거짓 정지

스크램블러 1유닛 = 메뉴의 연결(edge) 1개다. 유닛 수가 적으면 메뉴가 약해져 거짓 정지가 늘어난다. 유닛 수를 정하려고 작은 메뉴의 정지 수를 계산했다.

**(측정)** 무작위 연결 메뉴, 무작위 Enigma I 로터 순서 1개, 17,576 위치 전체, 대각선 보드 있음, 경우당 200회. 메뉴 구성 방법은 `crates/christopher-core/examples/stop_statistics.rs`와 같고(생성 트리 + 추가 연결), Python API(`Menu.from_edges`, `Bombe.run`)로 실행했다. 8·10글자 행은 `docs/results/stop_statistics.md`(400회)와 3% 이내로 일치한다(예: 8글자·루프 2개 57.1 ↔ 56.3).

| 6 | 4 | 3 | 17.8 | 0.69 |
| 6 | 5 | 2 | 310 | 11.9 |
| 7 | 4 | 4 | 0.88 | 0.03 |

| 8 | 6 | 3 | 7.8 | 0.30 |

(마지막 행은 `docs/results/stop_statistics.md`의 값.) 읽는 법: 루프 1개 추가 ≈ 1/25, 글자 1개 추가 ≈ 1/2–1/3.

실제 운용 기준은 로터 순서당 정지 1개 이상(기계 동작 확인), 약 4개가 한 사람이 감당할 최대였다 [@us6812report1944, p.31, p.44, p.49]. 관람객에게도 "정지가 한두 번 나오고 그중 하나가 정답"인 것이 가장 교육적이다(체킹의 의미가 드러난다).

**제안.**

| 단계 | 유닛 수 | 쓸 수 있는 메뉴 | 구동 범위 |
|---|---:|---|---|
| Phase 3.3 (소규모 뱅크) | **6** | 4글자·6연결·루프 3개 (K4 꼴, 거짓 정지 17.8/전체) | 26 × 26 구간(676 위치): 정답 1 + 거짓 0.69 |
| Phase 3.4 (확장) | **12** (영국 봄베 1뱅크와 같음 [@us6812report1944, p.43]) | 10글자·루프 3개(0.34/전체), 9글자·루프 4개 등 실제 크립에 가까운 메뉴 | 17,576 위치 전체 |

- 6유닛에서는 전체 구동을 하지 않는다(거짓 정지 약 18개). 7–8유닛이면 전체 구동도 가능하지만(5글자·루프 4개 0.47) 메뉴가 부자연스럽게 조밀하다.
- 4글자에 연결 6개가 들어가는 메뉴는 실제 크립에서는 드물다. 전시용 카드는 우리가 평문·키를 정해 만드는 것이므로, 원하는 모양의 메뉴가 나오는 전문을 소프트웨어로 찾아서 싣는다(가운데 로터 넘어감이 크립 구간에 없는 것도 함께 고른다, `docs/reference/bombe-mechanics.md` 8절).
- 기구 프레임·배선 패널·전원은 처음부터 12자리로 설계하고 6자리만 채운다. 나중에 나머지를 꽂으면 되게 한다.

## 3. 관람객 실습 흐름 (세 기계 공통)

실제 운용 절차(메뉴 → 배선 → 구동 → 정지 → 체킹, [@us6812report1944, pp.8–16, p.49])를 줄인 것이다.

| # | 단계 | 관람객이 하는 일 | 기어식 | 릴레이식 | FPGA |
|---|---|---|---|---|---|
| 1 | 카드 고르기 | 암호문·크립·메뉴 그림·드럼 설정이 인쇄된 메뉴 카드를 고른다. 카드의 태그(NFC 또는 QR)를 읽히면 화면이 그 카드의 안내로 바뀐다 | 같음 | 같음 | 같음 |
| 2 | 로터 순서 | 카드에 적힌 로터를 고른다 | 색 드럼 3종을 각 열에 끼운다 | 로터 배선 카드를 꽂는다(또는 고정) | 자동(카드 데이터) |
| 3 | 오프셋 | 유닛마다 크립 위치 글자(ZZA, ZZB …)를 맞춘다 [@us6812report1944, p.7] | 아래 드럼을 그 글자 방향으로 끼운다 | 유닛의 오프셋 다이얼을 돌린다 | 자동 |
| 4 | 메뉴 배선 | 26선 케이블로 유닛의 IN/OUT을 글자 잭에 꽂는다. 입력 글자 잭에 테스트 레지스터 케이블, 시험 선 플러그 1개 | 공통 패널 | 공통 패널 | 자동 — "배선이 데이터가 됐다"는 것을 보여 줌 |
| 5 | 구동 | 덮개를 닫고 Start | 드럼 회전 | 릴레이 동작음 | 즉시 끝남, 느린 재생 |
| 6 | 정지 | 기계가 멈추면 지시 드럼 3글자와 꺼진 램프(스테커 후보)를 정지 전표에 적는다 [@us6812report1944, p.49] | 지시 드럼 | 위치 표시 램프 | 화면 목록 |
| 7 | 체킹 | 정지값으로 나머지 스테커를 유도해 모순을 확인한다 | 화면(소프트웨어 체킹) 또는 실물 체킹 머신(선택, 12절) | 같음 | 자동 |
| 8 | 결과 | 정답이면 화면에 해독문이 나온다. 아니면 Start로 계속 | | | |
| 9 | 리셋 | 케이블을 뽑아 걸이에 걸고 Home | Carry Home | 계수기 리셋 | — |

- 3·4단계가 시간이 가장 많이 든다. 실제로도 배선·드럼 장착에 최대 30분이 걸렸다 [@jackson-bh11]. "빠른 체험" 카드는 배선을 미리 해 두고 마지막 케이블 2개와 Start만 관람객이 한다.
- 구동 중 정지는 정답 하나만이 아니라 거짓 정지도 나온다는 것을 일부러 경험하게 한다(2.3절).

## 4. 공통 전기 구조

### 4.1 블록

```
            ┌──────────── 공통부 (hardware/common) ───────────────┐
 메뉴 카드 →│ 메뉴 배선 패널: 글자 잭 26행 × 2 + commons            │
            │ 대각선 보드: 325 연결 고정 배선 (PCB)                 │
            │ 테스트 레지스터: 감지 릴레이 26 + 램프 26 + 정지 릴레이│
            │ 시험 전원 24 V (스트로브 접점 경유), 제어·안전 회로    │
            │ 감시 장치(MCU/FPGA): 26선·위치 읽기 → 기준 모델 대조   │
            └───┬──────────────────────────────┬──────────────────┘
      26선 IN/OUT × N, 뱅크 제어 커넥터   26선 IN/OUT × N, 뱅크 제어 커넥터
        ┌───────▼────────┐              ┌───────▼────────┐
        │ 기어식 뱅크     │              │ 릴레이식 뱅크   │      FPGA 전시물은 별도 장치
        │ (N 스크램블러)  │              │ (N 스크램블러)  │      (같은 카드 데이터 사용)
        └────────────────┘              └────────────────┘
```

공통부를 한 벌만 만들지(기어식·릴레이식이 번갈아 붙음), 기계마다 한 벌씩 둘지는 12절 결정 사항이다. 인터페이스는 어느 쪽이든 같다.

### 4.2 스크램블러 인터페이스 (Phase 3.0의 정의 대상)

스크램블러는 **수동 26선 양단 소자**다. 내부에 전원이 없고, IN의 i번 선과 OUT의 σ(i)번 선이 금속 접점으로 이어져 있을 뿐이다(σ = 현재 위치의 에니그마 치환, 양방향 대칭 [@ellsbury1998bombe, Part 2; @jackson-bh10]).

| 신호 | 방향 | 내용 |
|---|---|---|
| `IN[A..Z]`, `OUT[A..Z]` | 양방향 수동 | 26선 × 2. 유닛마다 잭 한 쌍 |
| `STROBE` | 뱅크 → 공통부 | "지금 접점이 안정됨". 이 동안만 시험 전압을 걸고 판정한다 |
| `RUN` | 공통부 → 뱅크 | 위치 진행 허가. 내리면 뱅크는 현재(또는 다음 안정) 위치에서 멈춘다 |
| `STOPPED` | 뱅크 → 공통부 | 멈춤 완료(드럼 정지/계수기 정지) |
| `HOME`, `AT_HOME` | 공통부 → 뱅크 / 뱅크 → 공통부 | 원위치 복귀 요청과 완료 |
| `END` | 뱅크 → 공통부 | 지정 범위(구간 또는 전체) 순회 완료 |
| `POS[3×5]` | 뱅크 → 감시 장치 | 세 자리 위치. **표시·대조 전용**이며 판정에 쓰지 않는다 |
| `ESTOP`, `ILOCK` | 직렬 안전 루프 | 비상 정지·덮개 인터록 접점 체인 |
| `+24V`, `0V` | 전원 | |

- 스크램블러 전류 정격 1 A 이상, 유닛 하나를 지나는 직렬 저항 10 Ω 이하를 목표로 한다 **(추정)**. 근거: 감지 릴레이 26개가 한 진입점을 통해 흐르므로 최대 26 × 코일 전류(4.5절).
- **시험 전압은 접점이 움직이는 동안 걸지 않는다.** 영국 봄베는 캠 구동 회로 차단기로 인덱스 점 앞뒤 1/4칸 동안만 감지 회로를 닫아 드럼 접점의 아크를 막았다 [@us6812report1944, p.73]. 같은 원칙(`STROBE`)을 두 트랙 모두에 적용한다: 접점은 무전류 상태에서 전환되어 수명이 기계적 수명에 가까워지고, 전환 중의 순간 개방이 거짓 정지로 읽히지 않는다. (미 해군식은 넓은 브러시가 인접 세그먼트를 단락시켜 차단기를 없앴다 [@turing1942ncr, (E); @desch1942memo, 원문 pp.7–8]. 채택하지 않는다.)
- 미 육군 릴레이 봄베는 연속 전압 대신 펄스를 썼고, 펄스 하나가 시험과 다음 위치 전환을 함께 일으켰다 [@dturing2021army]. `STROBE`/`RUN` 핸드셰이크는 이를 두 신호로 나눈 것이다.

### 4.3 메뉴 배선 패널

- 영국식(케이블 배선)을 따른다. 유닛마다 IN/OUT 잭 한 쌍, 글자마다 대각선 보드 잭, 한 글자에 연결이 여럿 모일 때 쓰는 commons [@us6812report1944, pp.8–10, p.59, p.68]. 미 해군식(유닛마다 26단 회전 스위치 2개 [@ekhall-hallenberg2018])은 26선 × 26위치 스위치가 기성품으로 없어 채택하지 않는다 **(추정: 기성품 조사 필요)**.
- 구성(12유닛 기준): 유닛 잭 24개, 글자 잭 26행 × 2개 = 52개, commons 4조 × 4잭, 테스트 레지스터 케이블 1개, 시험 선(searching) 플러그 1개 + 26구 잭, 26선 케이블 26개(여분 포함).
- **26선 커넥터가 가장 큰 미결 부품이다.** 실물은 납작한 핀 26개짜리 플러그(4¼ × 1 × 1½ in)를 썼다 [@us6812report1944, p.68]. 관람객이 하루 수십 회 꽂고 뽑으므로 결합 수명이 문제다. 후보 **(추정, 부품 조사·시험 필요)**:

| 후보 | 장점 | 약점 |
|---|---|---|
| D-sub 37핀(또는 고밀도 26핀) + 금속 후드 | 싸고 구하기 쉬움, 3.0 시제품용 | 일반품 결합 수명이 수백 회 수준, 핀 휨 |
| 산업용 사각 커넥터(다극 인서트) | 튼튼함, 손잡이·잠금 | 크고 비쌈 |
| 스프링 핀 + 자석 정렬 자작 커넥터(PCB 패드 26개) | 결합 수명 큼(스프링 핀 100만 회급 [@millmax-springpin]), 꽂는 느낌이 가벼움, 패드 쪽은 평판 PCB | 자작 하우징 필요, 이물질 관리 |

  권장: 3.0은 D-sub로 시작하고, 전시용은 스프링 핀 방식 시제품을 따로 시험한다. 어느 쪽이든 패널 쪽 잭은 **교체형 중간 어댑터**(소모품)로 보호한다.

### 4.4 대각선 보드

- 케이블 X의 y번 선 ↔ 케이블 Y의 x번 선, 325개 연결. 자기 글자 선(X의 x번)은 연결 없음 [@us6812report1944, p.6; @ellsbury1998bombe, Part 3, Part 5].
- 구현: 글자 잭 26개를 실은 백플레인 PCB의 고정 배선. 배선표는 스크립트로 생성해 넷리스트와 대조한다. 대각선 보드를 끊는 스위치(26 × 25선은 비현실적)는 두지 않고, "대각선 보드 없음" 비교는 화면(소프트웨어)으로 보여 준다(`docs/results/stop_statistics.md`: 루프 0–1개에서 사실상 모든 위치가 정지).

### 4.5 테스트 레지스터와 정지 판정

- 조건: **입력 케이블 26선이 전부 통전되지는 않으면 정지** (`docs/reference/bombe-mechanics.md` 6.1절의 결론, [@us6812report1944, p.29, p.32, p.50; @jackson-bh10]).
- 회로(제안): 입력 글자 잭에 꽂은 26선 각각에 감지 릴레이 1개(코일 반대쪽은 0 V). 시험 선 플러그가 고른 한 선에 `STROBE` 접점을 거쳐 +24 V. 감지 릴레이의 a접점 26개를 직렬로 이은 사슬이 닫히면 "26선 전부 통전"이고, `STROBE` 중에 사슬이 열려 있으면 정지 릴레이가 자기 유지되어 `RUN`을 내린다. 감지 릴레이 b접점으로 램프 26개를 켜서 **통전되지 않은 글자**(스테커 후보)를 보여 준다. 실물은 감지 릴레이 26 × 4조, 정지 릴레이 26개 등이었다 [@us6812report1944, p.69]. 우리는 입력 1계통이다.
- 감지 릴레이 요건: 동작 시간이 `STROBE` 폭보다 충분히 짧을 것. 실물의 Siemens형 감지 릴레이는 최소 동작 시간 0.002초였다 [@us6812report1944, pp.69–70]. 소형 신호 릴레이는 동작 시간 최대 4 ms(대표값 약 2.5 ms) [@omron-g6s]. 기어식의 `STROBE` 폭은 60 rpm에서 약 6 ms로 잡는다(`hardware/gear/concept.md` 5절).
- 전류: 코일 200 mW급(24 V에서 약 8 mA [@omron-g6s])이면 최대 26 × 8 mA ≈ 0.2 A가 진입점 접점을 지난다 **(추정)**.
- **감시 장치.** 26선과 `POS`를 광절연으로 읽어 기준 모델(Rust 코어 또는 FPGA)의 예상 레지스터 값과 비교한다. 불일치는 고장 진단으로만 쓰고, 정지 여부는 릴레이가 정한다(`docs/PLAN.md`: "해독 동작 자체는 기계가 한다").
- 부가 기능(double input, CSKO, machine gun 등 [@us6812report1944, p.25, p.29])은 넣지 않는다.

### 4.6 정지 뒤 표시

실제 조작자가 읽은 것(지시 드럼 3글자, 떨어진 릴레이 글자, 정지 전표 [@us6812report1944, p.49])을 그대로 둔다. 지시 드럼 글자는 역방향 눈금과 드럼별 오프셋이 있다(`docs/reference/bombe-mechanics.md` 4절). 화면에는 "지시 드럼 값"과 "코어 위치"를 함께 보여 준다.

### 5.2 권장 시나리오 A — "26 × 26 구간" (6유닛)

- 메뉴: 4글자·6연결·루프 3개. 카드가 아래(느린) 드럼의 글자를 알려 주고, 기계는 위·가운데 드럼만 한 바퀴씩(676 위치) 돈 뒤 `END`로 멈춘다.
- 예상 정지 수 = 정답 1 + 거짓 17.8 × 676/17,576 = **1.69회** **(측정에서 계산)**. 거짓 정지가 0회일 확률은 약 50%(푸아송 근사 e^−0.69).

| 구간 | 기어식 | 릴레이식 | 근거 |
|---|---:|---:|---|
| 카드 선택·설명 읽기 | 0.5분 | 0.5분 | (추정) |
| 드럼/카드 장착, 오프셋 6개 | 1.5분 | 1분 | (추정) |
| 케이블 13개 배선 | 3분 | 3분 | 초보자 케이블당 약 15초 (추정) |
| 구동(정지 없음) | 0.5분 | 0.3분 | 5.1절 |
| 정지 1.69회 × 1분(읽기·체킹·재시작) | 1.7분 | 1.7분 | 숙련 조작자는 정지 4개에 5–10분을 더 썼다(15–20분 − 10.4분 [@us6812report1944, p.49]) → 정지당 1.2–2.4분. 화면 체킹으로 1분 가정 (추정) |
| 리셋 | 1분 | 0.5분 | (추정) |
| **합계** | **약 8분** | **약 7분** | |

- "빠른 체험"(배선 완료 상태에서 케이블 2개 + 구동 + 정지 확인): 약 3분.
- FPGA는 같은 카드로 같은 구간을 0.2 ms, 60개 로터 순서 전체를 약 0.3초에 끝낸다. 화면에 "기어식 30초 / 릴레이식 17초 / FPGA 0.0002초"를 실측값으로 나란히 보여 준다.

### 5.3 시나리오 B — 전체 구동 (12유닛, 해설자 시연용)

- 메뉴: 10글자·12연결·루프 3개. 거짓 정지 0.34회 + 정답 1회 **(측정에서 계산)**.
- 기어식 13.0분 + 정지 1.3회 ≈ 14–15분, 릴레이식 7.3분 + 정지 ≈ 9분. 실물 봄베의 정지 없는 1회 구동 10.4분, 재현기 시연 약 18분과 같은 규모다 [@jackson-bh09; @carter2010bombe].
- 관람객 자유 실습용이 아니라 정해진 시간의 시연용이다.

### 5.4 시나리오 C — 한 바퀴 (26 위치)

위 드럼 한 바퀴(기어식 약 1초, 릴레이식 관찰 모드 6.5초)만 돌려 "정답 위치에서만 램프 하나가 꺼진다"를 보여 주는 가장 짧은 시연. 거짓 정지 기대값 17.8 × 26/17,576 = 0.03.

## 6. 안전

| 위험 | 대책 |
|---|---|
| 감전 | 노출되는 모든 회로는 24 V DC. 극저전압(ELV)의 상한은 교류 50 V, 직류 120 V다 [@iec61140] (표준 원문은 직접 열람하지 못함). 상용 전원은 인증된 SELV 전원 장치 안에서만 다루고 관람객 쪽으로 나오지 않게 한다. 참고로 실물은 220 V DC, 약 10 A였다 [@us6812report1944, p.59] |
| 단락·과열 | 시험 전원과 각 보드에 자동 복귀 퓨즈, 케이블·잭은 어떻게 꽂아도 전원끼리 닿지 않는 구조(26선은 전부 신호선) |
| 끼임(기어·드럼) | 회전부 전체를 투명 덮개로 가리고, 덮개 스위치 2개 직렬(`ILOCK`)이 열리면 모터 전원 차단. 드럼 교체는 덮개를 연 정지 상태에서만 |
| 과부하·걸림 | 구동계에 토크 제한 요소(슬립 클러치 또는 전단 핀) + 모터 전류 제한. 실물도 기어 쌍마다 한쪽을 파이버 기어로 해 걸리면 먼저 부서지게 했다 [@us6812report1944, pp.70–73] |
| 비상 | 잠금형 비상 정지 버튼(`ESTOP`)을 기계마다 전면에. 모터 전원과 시험 전원을 함께 끊는다 |
| 브러시·핀 | 스프링 접점을 관람객이 만지는 드럼이 아니라 기계 쪽 교체형 모듈에 둔다(`hardware/gear/concept.md` 3절) |
| 열(릴레이식) | 6유닛에서 코일 소비 약 0.2–0.3 kW **(추정)**. 통풍, 보드 온도 감시, 유휴 시 자동 대기 |
| 소음 | 릴레이식 빠른 모드의 소음도를 시제품에서 측정하고 덮개로 조절 |

전시 장소의 안전 기준(전기·기계)은 장소가 정해지면 따로 확인해야 한다.

## 8. 자가 진단

| 단계 | 내용 |
|---|---|
| 유닛 진단 | 진단 장치가 유닛 하나의 IN 26선에 차례로 전압을 걸고 OUT 26선을 읽어(26 × 26) 현재 위치의 치환을 Rust 코어의 표와 비교한다. 26개 위치(또는 전체)를 자동으로 훑어 불량 접점의 글자·위치를 알려 준다. G.1·R.1·G.2·R.2의 완료 기준이 바로 이 시험이다 |
| 공통부 진단 | 유닛 자리에 고정 배선 플러그를 물려 정지/통과가 예상대로 나오는지 확인(Phase 3.0 완료 기준) |
| 기준 메뉴 | 개관 전 기준 메뉴 카드를 걸고 알려진 정지 위치와 스테커 후보가 나오는지 확인. 실물의 "check stop"과 같은 생각이다 [@us6812report1944, p.15, p.53] |
| 상시 감시 | 구동 중 감시 장치가 매 위치의 26선 상태를 기준 모델과 비교(4.5절). 체킹에서 illegal contradiction이 나오면 기계 고장이라는 실물의 규칙 [@us6812report1944, pp.12–16]을 자동화한 것 |

## 9. 리셋

- 배선: 케이블을 색·번호로 구분하고 걸이를 둔다. 패널 잭마다 꽂힘 감지 접점을 두어 "아직 꽂혀 있는 잭"을 화면에 표시 **(선택 사항)**.
- 위치: Home 버튼 → 기어식은 원위치(실물의 "Carry Home" [@us6812report1944, p.59, p.69]), 릴레이식은 계수기 프리셋.
- 정지 릴레이·램프 해제, 화면 초기화, 일정 시간 조작이 없으면 자동 대기.

## 10. 소프트웨어와 FPGA의 역할

| 장치 | 역할 |
|---|---|
| Rust 코어 + Python | 메뉴 카드 제작(전문·크립 선택, 메뉴 모양·넘어감 조건 검색), 예상 정지 목록, 체킹, 해독문 표시, 진단용 기준표 |
| 감시 장치(MCU 또는 소형 FPGA) | 26선·위치 읽기, 기준 모델 대조, 진단 시퀀스, 실측 속도 계측. 판정·구동 논리에는 끼지 않는다(모터 드라이버 제어는 예외) |
| FPGA 전시물 (`rtl/fpga`) | 세 번째 봄베. 같은 카드 데이터를 받아 탐색. 움직이는 부품이 없으므로 표시 장치가 전시물의 몸이다: ① 26 × 26 = 676선 상태 표시(전파가 퍼지는 모습), ② 드럼 위치 3글자, ③ 정지 목록, ④ 느린 클럭 재생(한 클럭씩) ↔ 실제 속도 전환, ⑤ 속도 비교 막대 |
| 화면 | 카드별 안내, 정지 전표, 체킹 결과, 세 기계의 실측 시간 비교, "대각선 보드가 없다면" 비교 |

FPGA 표시 수단은 12절 결정 사항이다(모니터만 / 676 LED 패널 추가).
