## 2. 한 자리의 회로 (11 릴레이)

### 2.1 아이디어

비트마다 **슬레이브 릴레이 KS**(값을 갖고, 접점이 `CTRL`을 구동)와 **마스터 릴레이 KM**(항상 KS의 **반대값**을 따라가는 거울)을 둔다. 한 자리의 증가는 이진 올림 사슬에서 "토글해야 하는 비트"를 가려내고, 그 비트의 슬레이브가 마스터 값을 **한꺼번에** 받는 동작이다: 토글이므로 새 값 = 마스터 값 = 옛 값의 반대. 마스터가 클럭 동안 변하지 않으므로 올림 사슬은 접점만 지나가고 릴레이 동작을 기다리지 않는다(파문 올림이 아니라 순간 전달, 경주 없음).

신호는 모두 24 V "레일"(접점·다이오드를 거쳐 전달되는 +24 V)이고, 증가/정지는 상보 쌍으로 다룬다.

| 이름 | 뜻 |
|---|---|
| `AIN` / `ZIN` | 증가 레일 / 정지 레일 (항상 하나만 켜짐, 클럭 구간에서 `AIN` = 클럭 펄스 ∧ 이 자리의 증가 조건) |
| `AOUT` / `ZOUT` | 올림(25 → 0) 레일 쌍 = 다음 자리의 `AIN` / `ZIN` 재료 |
| `NOUT` | `AIN` ∧ (값 ≠ 25) |
| `P0..P4` | 프리셋 코드(다이얼). 24 V는 `LOAD` 동안에만 걸린다 |
| `Q0..Q4` | 값의 각 비트(1이면 24 V) = `CTRL` |

### 2.2 구성 (비트 i = 0..4)

- **KS_i** (극 1: COM = +24 V, NO → `Q_i`, NC → `NQ_i`; 극 2: COM = 레일 `Z_i`, NC → 마스터 거울, NO → 자기 유지).
- **KM_i** (극 1: COM = 사슬 `A_i`, NC → `A_{i+1}`(사슬 계속), NO → `G_i`(마스터 유지 + 슬레이브 적재 급전); 극 2: COM = `AIN`, NO → `Y_i` = `AIN` ∧ KM_i).
- **KW** (한 자리에 하나): 코일 = `NQ0 ∨ NQ4 ∨ NQ3`(다이오드 OR) = "값 ≠ 25". 접점 두 극이 비트 1, 2의 마스터 거울 경로에 직렬로 들어간다.
- 올림 사슬: `A_0 = AIN`, `A_{i+1} = A_i ∧ (마스터 i = 0)`(마스터 NC 접점) → 비트 i는 `A_i`가 올라올 때 토글. `A_5` = `AOUT`.
- 정지 레일: `Z_t = ZIN ∨ Y_0 ∨ … ∨ Y_{t−1}`(병렬 다이오드 OR, 한 노드에 다이오드 한 개 전압 강하) = `NOT A_t`.
- 슬레이브 코일 급전(다이오드로 OR): ① 자기 유지(레일 `Z_i` → KS 극 2 NO), ② 적재(`A_i` → KM NO = `G_i`, 마스터가 1일 때), ③ 프리셋(`P_i`). 마스터 코일 급전: ① 거울(레일 `Z_i` → KS 극 2 NC; 비트 1, 2는 KW 접점 경유), ② 유지(`G_i`).
- 코일마다 역기전력 다이오드(1N4148W), 급전·OR 다이오드는 쇼트키(1N5819W, 강하 약 0.3 V — 코일 전압 확보). 비트마다 `Q`에 저항 4.7 kΩ + LED(값 표시, 5 mA).

### 2.3 동작 (한 클럭)

클럭은 **두 상**이다. `NCK`(= 평상시 켜짐)와 `CK`(= 확정 펄스). 상보이며 겹치지 않는다(2.5절).

| 상 | 레일 | 마스터 | 슬레이브 |
|---|---|---|---|
| φ1 (`NCK`, 평상시) | 모든 `Z_i`가 켜짐, `A_i` 꺼짐 | 슬레이브의 반대값을 계속 따라감(**미리 계산**) | 자기 유지 |
| φ2 (`CK`, 확정) | `AIN`이 켜진 자리: 토글 비트의 `Z_i`가 꺼지고 `A_i`가 켜짐 | 토글 비트: 자기 유지(`G`)로 값을 붙잡음. 나머지: 계속 거울 | 토글 비트: 마스터 값을 받음. 나머지: 유지 |

- **정지**: `AIN` = 0이면 모든 `A_i` 꺼짐, 모든 슬레이브가 `Z_i`로 유지된다.
- **25 → 0**: 값이 25 = `11001b`일 때 KW가 꺼져 비트 1, 2의 거울이 끊기고(마스터는 `00000`), 이때만 마스터 전부가 0이 된다(정상 값에서 마스터 = NOT 값이 0이 되려면 값 = 31이어야 하므로 도달 불가). 마스터 NC가 모두 닫혀 있으므로 `A_0 … A_4`가 전부 올라와 슬레이브 다섯 개가 모두 0을 받는다. `A_5`가 올라와 **올림 = `AOUT` = `AIN` ∧ 값 = 25**가 된다. 따라서 25 → 0을 별도 감지·리셋 없이(과도 값 26 없이) 같은 사슬이 처리한다.
- 정상 증가에서 `A_{i+1} = A_i ∧ 슬레이브 i`이므로 이진 +1과 같다. 이진 코드 직접 구동이므로 시프터에 중간값이 안 보인다.
- `ZOUT = NOT AOUT`는 정지 레일이 상보를 유지하게 하는 쌍이다(`NCK`가 꺼진 φ2에서도 올림이 없으면 켜짐).

### 2.4 릴레이 수 (concept.md 추정과 비교)

한 자리: KS 5 + KM 5 + KW 1 = **11개**. `concept.md` 5.2절의 "비트당 2개 × 5 + 리셋·올림 2–3개 ≈ 13개"보다 2개 적다(올림은 마스터 접점 사슬이 하고, 26진 처리는 KW 하나다). 대신 다이오드가 한 자리 64개다(급전 25 + 정지 레일 OR 20 + `NOUT` OR 5 + KW 3 + 역기전력 11). 2연 다이오드 소자(SOT-23)를 쓰면 부품 수는 절반 근처로 준다 **(추정)**.

| 보드 | 자리 | 릴레이 | 비고 |
|---|---|---:|---|
| 공통 | pL, pM, a3 | 33 | `concept.md` 5.2절의 공통 계수 39 대비 −6 (클럭 발생·시작·정지·Home 제어 약 8은 별도 시퀀서) |
| 유닛 | a2, a1 | 22 | `concept.md`의 26 대비 −4 |
| 유닛 | a3/a4 중계 | 10 | 코일 = 공통 코드선, 접점 두 극 병렬 = 이 유닛의 `CTRL` 선 (`concept.md`의 "중계 릴레이 약 10") |
| 유닛 합계 | | **32** | `concept.md` 36 대비 −4 |
| 6유닛 합계 | | **225** (= 33 + 6 × 32) | `concept.md` 266 대비 |
| 12유닛 합계 | | **417** | `concept.md` 482 대비 |

이 비교에는 그 뒤에 더한 공통 보드의 pR(11개, 0003 K3)과 클럭 버스 B의 쌍둥이 주 릴레이(10개, 0003 K7, 11절)가 들어 있지 않다. 지금의 공통 보드는 54개, 12유닛 합계는 438개(= 54 + 12 × 32)다 **(계산)**.

(공통 클럭 발생·시퀀서는 이 보드에 없다.)

### 2.5 시퀀서에 요구하는 것

- `CK`/`NCK`는 **하나의 전환(c) 접점**에서 나온다(COM = +24 V, NO → `CK`, NC → `NCK`). 개별 릴레이 둘로 만들어 둘 다 켜지면 값이 틀어진다(시뮬레이션에서 확인: "info" 줄). 전환 중 양쪽이 모두 꺼지는 순간(break-before-make)은 릴레이 복귀 시간(3–5 ms, 결정 0001)보다 충분히 짧아야 한다(수 백 µs).
- **HOME(프리셋)**: ① `CK` = `NCK` = 0(전부 꺼짐)으로 모든 릴레이를 풀고, ② `LOAD` = 24 V로 다이얼 공통선에 전압을 걸어 슬레이브가 `P`를 받게 하고, ③ `NCK`를 올리되 **`LOAD`는 그 뒤에 내린다**(겹침 또는 틈 없이). `LOAD`가 `NCK`보다 먼저 내려가는 틈이 릴레이 복귀 시간보다 길면 프리셋이 지워진다(시뮬레이션: 틈 있는 순서는 실패).
- 전원 투입 직후의 릴레이 상태는 임의이며, 위 절차가 어떤 상태에서도 올바른 값을 만든다(무작위 초기 상태로 확인).

## 3. 계수 규칙의 배치 (`relay.rs` `Counters`)

| 계수기 | 증가 조건 | 구현 (`AIN` / `ZIN`) |
|---|---|---|
| pL (a4 = l) | 매 클럭 | `AIN = CK`, `ZIN = NCK` |
| pM | l이 25 → 0 | `AIN = LC` (= pL의 `AOUT`), `ZIN = ZL` (= pL의 `ZOUT`) |
| a3 = l − m | 매 클럭, 단 l이 25 → 0이면 정지 | `AIN = NL` (= pL의 `NOUT` = `CK ∧ l ≠ 25`), `ZIN = NCK ∨ LC` (다이오드 2개) |
| a2 | pM이 증가하고 m이 25 → 0이 아님 | `AIN = A2B` (= pM의 `NOUT` = `CK ∧ l 올림 ∧ m ≠ 25`, pM의 접점 극 2의 COM을 `LC`로 둔 덕분에 다이오드 없이 AND), `ZIN = Z2B = ZL ∨ A1B` (다이오드 2개) |
| a1 | m이 25 → 0 | `AIN = A1B` (= pM의 `AOUT`), `ZIN = Z1B` (= pM의 `ZOUT`) |

- **공통 보드**: 위 다섯 규칙 전부와 pM·a3 자리의 판정이 여기 있다. 유닛으로는 레일 4개(`A2B`, `Z2B`, `A1B`, `Z1B`)와 a4/a3 코드 10선(`L0..4`, `T0..4`)만 나간다.
- **유닛 보드**: 규칙 논리가 **없다**. a2/a1 자리는 공통 레일을 받아 증가/정지만 하고, 프리셋만 유닛별이다(다이얼: a1 = k, a2 = −k mod 26).
- pL·pM·a3의 `P0..P4`는 0 V에 묶어 **프리셋 = 0(clear)**. 오프셋과 무관하게 HOME에서 l = m = 0, a3 = 0이다.
- 모든 올림·판정이 **마스터 값**(φ2 동안 불변)에서 나오므로, 같은 클럭에서 슬레이브가 바뀌어도 규칙 신호가 흔들리지 않는다. 한 클럭의 모든 계수기가 같은 `CK` 펄스 안에서 동시에 움직이고, 사이의 순서(예: pM이 l보다 먼저/나중)가 없다.

## 4. 타이밍 (결정 0001과의 관계)

위치 한 칸(`concept.md` 6절)의 순서: **`CK` 펄스 → 슬레이브 전환 → (a3/a4는 중계 릴레이) → 시프터 전환·바운스 → `STROBE` → 감지 → `JUDGE` → `CLEAR` → `CK` 복귀 → 다음 `CK`**.

| 구간 | 대표 | 최대 | 비고 |
|---|---:|---:|---|
| 슬레이브 동작 (`CK` 상승부터) | 2.5 | 4 | a1, a2는 여기서 `CTRL` 확정 |
| a3/a4 중계 릴레이 | 2.5 | 4 | a3, a4만 해당(슬레이브 + 중계 = 5 / 8 ms). a1, a2는 중계 없이 슬레이브 접점이 시프터 코일을 구동 |
| `CK` 펄스 폭 | | ≥ 4 + 튐 1 = 5 | 슬레이브가 끝까지 움직일 때까지 `CK` 유지 **(계산)** |
| 마스터 재계산 (`CK` 하강부터) | 2.5 | 4 (복귀는 다이오드 포함 최대 10) | 슬레이브가 바뀐 뒤 KW와 마스터가 새 거울을 만든다. **`STROBE`·판정과 겹치는 구간**이므로 위치 시간에 더해지지 않는다 |

- 결정 0001의 표(대표 약 20 ms, 최대 약 33 ms)에서 계수기 항목(릴레이 2단, 대표 5 / 최대 8 ms)과 중계 릴레이(2.5 / 4 ms)는 이 설계에서 a3/a4 경로 = 슬레이브 + 중계(5 / 8 ms)와 a1/a2 경로 = 슬레이브 1단(2.5 / 4 ms)으로 줄어든다. 마스터는 "미리 계산"으로 클럭 경로 밖에 있으므로 클럭 경로에는 **슬레이브 1단**만 있다. 그러므로 표의 두 항목 합(7.5 / 12 ms)이 최악 경로 5 / 8 ms로 줄어 합계는 대표 약 17.5 / 최대 약 29 ms **(계산)**.
- 마스터가 다음 `CK` 전에 정착해야 한다: 슬레이브(4) → KW(4) → 마스터(복귀 최대 10) ≈ 18 ms 최대 **(계산)**. `CK` 하강부터 다음 상승까지 25 ms 목표에서 `CK` 폭 5 ms를 빼면 20 ms가 남아 맞는다. 33 ms 예비안에서도 성립. 이 여유는 R.1에서 실측(항목 2).
- `JUDGE`·`CLEAR`는 테스트 레지스터 쪽 신호이며 계수기와 신호를 주고받지 않는다. 다음 `CK`는 `CLEAR` 뒤에만 나가도록 클럭 시퀀서가 정한다(계수기 보드는 이를 모른다).
- 관찰 모드(≤ 4 위치/초)와 한 스텝 버튼: `CK`를 한 번 누르는 것이 한 클럭이다. 마스터가 자동으로 다음 값을 준비해 두므로 버튼 사이 간격에 제약이 없다.

| 공통 | J6 | UNIT_BUS_B (DB25) | **유닛 7–12**, J2와 같은 배치: 1 `A2B_B`, 2 `Z2B_B`, 3 `A1B_B`, 4 `Z1B_B`(버스 B의 레일, J5에서만 먹음), 5–14 `L0..L4`·`T0..T4`(J2와 같은 넷), 15 `LOAD_B`, 16–18·22–25 예약, 19–21 0 V. 유닛 보드는 같은 것이고 어느 리본에 꽂히는지만 다르다. 11절 |
| 공통 | J3 | 24V_IN (5.08 mm 2극 단자) | 1 = +24 V, 2 = 0 V. 보드의 +24 V는 여기서만 받는다(PTC 1 A → 직렬 P채널 MOSFET → TVS 33 V + 100 µF) |
| 공통 | J4 | POS (DB25 핀) | 1–5 `POS0–4` = l(pL의 `Q0–4`, 넷 `L0..L4`), 6–10 `POS5–9` = m(pM, 넷 `M0..M4`), 11–15 `POS10–14` = r(pR, 넷 `R0..R4`), 16–18·22–25 예약, 19–21 0 V. 24 V 레벨, 1 = 높음, 비트 0이 가장 낮은 자리. **k는 들어 있지 않다**(0003 4.5절). 순서기 보드를 거쳐 제어 커넥터 7–21번으로 간다 |
| 유닛 | J1 | BUS (DB25) | 공통 J2와 같은 핀 배치 (1:1 케이블) |
| 유닛 | J2 | DIAL (DA15) | 1 `DIAL_COM`(= `LOAD`, 다이얼 공통선), 2–6 a1 프리셋 코드(비트 0..4, = k), 7–11 a2 프리셋 코드(= −k mod 26), 12–13 0 V, 14–15 예약. 다이얼 접점이 `COM`과 1인 비트의 코드 핀을 잇는다. 다이얼: `hardware/relay/offset-dial`(26위치 코드 트랙 스위치, 이 커넥터를 바꾸지 않음) |
| 유닛 | J3–J6 | CTRL_A1..A4 (DE9) | 1–5 `CTRL0..4`(시프터 보드 J5와 같은 핀 배치), 6–7 0 V. 시프터 보드 a1, a2, a3, a4(거꾸로 끼움)에 각각 연결 |
| 유닛 | J7 | 24V_IN (5.08 mm 2극 단자) | 1 = +24 V, 2 = 0 V. PTC 4 A → 직렬 P채널 MOSFET → TVS + 100 µF. 유닛마다 전원부에서 퓨즈를 거쳐 따로 받는다 |

모든 보드의 D-sub 껍데기(풋프린트 패드 `SH`)와 장착 구멍 H1–H4(도금 M3)는 넷 `CHASSIS`이고 0 V가 아니다. `CHASSIS`–0 V에 RCH1 1 MΩ ∥ CCH1 10 nF/100 V 한 벌. **신호 커넥터에는 전원이 없다**(5.1절 5항): 전원은 J3·J7만 받는다.

## 6. 전력과 접점 부하

릴레이 G6S-2급 24 V, 코일 140–200 mW(`concept.md` 4절) **(계산)**: 한 자리에서 슬레이브와 마스터는 비트당 하나씩 켜져 항상 5개 + KW(25 제외 항상 켜짐) = 약 6개 → 0.84–1.2 W, LED 약 0.26 W (값이 평균 44%일 때) → **한 자리 1.1–1.5 W**.

| | 공통 | 유닛 (a2 + a1 + 중계) |
|---|---:|---:|
| 계수 릴레이 | 3.3–4.5 W | 2.2–3.0 W |
| 중계 릴레이 (평균 4.4개) | | 0.6–0.9 W |
| 합계 | **약 3.3–4.5 W** | **약 2.8–3.9 W** (시프터 보드 32–46 W 별도) |

- `CTRL` 접점: a1, a2는 슬레이브 극 1이 시프터 한 단(26 코일 + LED, 약 157–222 mA, 시프터 README 4절)을 직접 구동 — 접점 정격 2 A 안쪽. a3, a4는 중계 릴레이 두 극 병렬(양쪽에서 약 0.22 A).
- 코일 전압 **(계산)**: 가장 깊은 경로는 a2의 마스터 거울(공통 접점 → 다이오드 `Y→Z` → 다이오드 `Z2B` → 다이오드 `Z_t` → 급전 다이오드) 쇼트키 4개 ≈ 1.2–1.6 V. **보드 단자에서 23.0 V 이상**(결정 0003 6절: 전원 장치를 24.5 V ± 0.5로 맞추고 배선 강하를 1 V 안으로)이면 23.0 − 1.6 = 21.4 V = 정격의 89 %이고 동작 전압(정격의 80 % = 19.2 V, **미확인**)에 여유가 있다. 전원 장치 허용 하한 21.6 V까지 내려가면 약 20 V(83 %)로 여유가 작으므로 전원 장치를 맞추는 쪽으로 닫는다(열린 질문 2, 10절). 전원 입력의 직렬 P채널 MOSFET은 강하 0.1 V 이하(직렬 다이오드는 코일 전압을 깎으므로 쓰지 않는다).
- 전원 보호(0003 7.3절): J3·J7 → 자동 복귀 퓨즈(공통 1 A, 유닛 4 A 유지 **(품번 미확인)**) → 직렬 P채널 MOSFET Q1(드레인 = 공급 쪽, 게이트에 제너 12 V + 100 kΩ) → TVS 33 V(SMAJ33A급)와 100 µF/35 V. 공통 보드는 레일 신호와 계수 코일만 다루므로 1 A, 유닛 보드는 시프터 보드 4장의 코일 전류(최악 약 2.5–3.6 A)가 `CTRL` 선을 거쳐 이 보드의 슬레이브·중계 접점(COM = 보드 +24 V)에서 나가므로 4 A로 둔다(0003 6절).

## 7. 재생성과 검증

KiCad 10과 Python 3(표준 라이브러리만)이 필요하다. 표준 심볼 위치는 `KICAD_SHARE`(기본 `C:/Program Files/KiCad/10.0/share/kicad`), `kicad-cli`는 PATH 또는 `KICAD_CLI`.

```
python gen_counter.py                                                     # 회로도 재생성
kicad-cli sch erc --severity-all --format json -o erc.json counter_common.kicad_sch   # (counter_unit도 같이)
python verify_counter.py                                                  # 넷리스트 내보내기 + 시뮬레이션 + 음성 시험 (약 2분; --quick은 약 15초)
kicad-cli sch export pdf -o counter_common.pdf counter_common.kicad_sch   # PDF는 저장소 밖에 둘 것
```

- **ERC**(KiCad 10.0.4, 모든 심각도): 공통·유닛 두 보드 모두 위반 **0건**(오류 0, 경고 0). 미사용 접점·핀은 `no_connect` 표시. 시트: 공통 루트 + 자리 4장(pL, pM, a3, pR), 유닛 루트 + 자리 2장 + 중계 1장.
- **시뮬레이션** `verify_counter.py`: 두 보드의 계층 넷리스트(kicadsexpr)만 읽고(생성기 지식 없음) 접점 단위로 푼다. 코일은 "+24 V 또는 외부 구동 넷에서 닫힌 접점(양방향)·순방향 다이오드(음극 방향)·고정 배선(케이블, 다이얼)으로 코일 + 핀에 닿는 경로가 있으면 여자"이고(코일·저항·LED는 전도하지 않음, 0 V에 닿으면 단락 오류), 한 입력 벡터마다 릴레이 상태를 고정점까지 반복한다. 자기 유지 경로가 있으므로 상태를 벡터 사이에 이어 간다. 동기 모드(불안정 릴레이 모두 동시 전환)와 비동기 모드(불안정 릴레이 중 무작위 하나씩 전환 = 경주 확인) 둘 다 쓴다.
- **기준 모델**: `relay.rs` `Counters`/`Controls::from_cores`의 **Python 직접 이식**(Rust 호출 아님). 검증기가 먼저 이식본이 크립 오프셋 26종 전체에서 17,577 스텝 내내 `from_cores`와 일치하고 한 바퀴가 HOME으로 돌아옴을 확인한다(Rust 테스트 `counters_track_controls_over_full_run`과 같은 검사).
- **결과**:
  - 구조: 공통 릴레이 54·다이오드 279, 유닛 릴레이 32·다이오드 138, 모든 코일 − 단자가 0 V. 결정 0003 항목(10절): 전원 입력 사슬(단자 → PTC → MOSFET의 드레인, 소스 → 보드 +24 V → 게이트 제너·저항·TVS·커패시터), 신호 커넥터의 어느 핀도 +24 V가 아님(예약 핀은 단독), `CHASSIS` = H1–H4 + 껍데기 + RCH1/CCH1이고 0 V와 별개, POS 커넥터 핀. K7(11절): J5의 `CK_B`/`NCK_B`/`LOAD_B`가 버스 A의 넷이 아님, J6이 J2와 같은 배치이되 레일 다섯(1–4, 15번)은 버스 B만의 넷이고 코드선·0 V는 J2와 같은 넷, 쌍둥이 주 릴레이 10개의 코일이 짝인 주 릴레이 코일과 병렬.
  - 자리 단독(유닛 보드 단독 구동): 프리셋 값 0..25 각각 × 무작위 증가/정지 60 스텝 = 1,560 스텝, 값과 올림 레일(`AOUT` = 증가 ∧ 값 25)이 기대와 일치, 해제 후 안정.
  - HOME 프리셋: 오프셋 26종 전부(무작위 초기 릴레이 상태, 계수 후 재프리셋), 그리고 HOME 절차 변형 4가지(겹침, 직접 전달, 전원 투입에서 시작) 150회. 프리셋 후 `CTRL` = `Counters::home(k)`(a1 = k, a2 = −k mod 26, a3 = a4 = 0).
  - **버스 분리**(11절): 무작위 릴레이 상태 300가지에서, 한 클럭 버스(`CK`, `NCK`, `LOAD`)와 보드 +24 V에서 닿을 수 있는 곳에 다른 버스의 `CLOCK` 핀·유닛 버스 레일 핀이 하나도 없다. 곧 유닛 7–12의 레일 전류는 J5로만, 공통 자리와 유닛 1–6의 레일 전류는 J1로만 들어온다.
  - 전체 구동: 공통 1 + 유닛 3(오프셋 3개; 첫째·셋째 유닛은 J2 = 버스 A, 둘째 유닛은 **J6 = 버스 B**)을 한 시스템으로 묶어 **17,576 클럭**(+ 시작 상태 확인), 오프셋 **0..25 전부**(9회 × 3유닛, 0·7·25 포함). **매 클럭마다 확정(`CK` 상승 직후)과 해제 후 두 시점**에서 모든 유닛의 시프터 `CTRL` a1..a4가 기준 `Counters`와 같고, 내부 자리(pL = l, pM = m, **pR = r**, a3, a2, a1)의 슬레이브값이 기대와 같고 마스터가 "슬레이브의 반대(25에서는 0)"임을 확인. **공통 보드 `POS` 커넥터 J4(l, m, r 각 5비트, k 없음)가 매 클럭마다 확정·해제 두 시점에서 코어 위치와 같음**(17,576 클럭 × 9회). 불일치 0.
  - 경주: 비동기(무작위 순서) 17,576 클럭 + 프리셋 26종, 무작위 초기 상태 — 통과.
  - **버스 어긋남**(11절): 순서기의 두 버스 릴레이가 따로 움직이는 경우. 매 클럭 무작위로 오름은 A 먼저·B 먼저·동시, 내림은 B 먼저·동시로 넣고 비동기 풀이, 유닛 넷(A, B, A, B), 17,576 클럭 — 통과. 내림에서 B가 늦는 쪽은 시간의 문제라 이 모델로 보일 수 없고 11.3절의 계산으로 보인다.
  - 음성 시험: 넷리스트 복사본에서 버스선 교환, KS·KM·KW 접점 NC/NO 교환, 다이오드 반전(슬레이브 유지, 올림 OR), 다이얼 비트 교환, 중계 코일 반전, 커넥터 핀 교환 등 14종 + 결정 0003 항목 14종(역방향 P채널 MOSFET 2, PTC 우회, 게이트 제너 반전, TVS 이탈, 신호 커넥터의 +24 V 2, 장착 구멍·RCH1·0 V 핀의 `CHASSIS` 오결선 3, `POS` 핀 교환(구조·시뮬레이션 2), pR 슬레이브·마스터 접점 교환 2) + **K7 항목 7종**(J6의 `A1B_B`/`Z1B_B` 교환, J5의 `CK_B`/`NCK_B` 교환, pM 쌍둥이의 올림 접점 NC/NO 교환, pL 쌍둥이의 `YB` 접점 NC/NO 교환 — 시뮬레이션이 버스 B 유닛의 값으로 잡음; `Z2B_B` OR 다이오드를 버스 A의 `ZL`에서 먹임 — 버스 분리 검사가 잡음; 쌍둥이 코일이 주 릴레이와 병렬이 아님, `LOAD_B` 핀을 버스 A의 `LOAD`에 — 구조 검사가 잡음) = 35종이 전부 실패로 잡힌다.
- 한계: 이 시뮬레이션은 **논리·접점 연결 수준**이다. 릴레이 동작·복귀 시간, 튐, 코일 전압 강하(6절), 역기전력 다이오드로 늘어난 복귀 시간은 모사하지 않는다(열린 질문 1–3). 클럭 전환 중 양쪽이 모두 꺼지는 순간은 "릴레이 상태 유지(관성)"로 가정한다.

## 8. 열린 질문

1. **break-before-make 틈과 튐.** `CK`/`NCK` 전환의 틈(양쪽 꺼짐)이 마스터·슬레이브의 복귀 시간보다 충분히 짧은지, `CK` 접점 튐이 마스터 유지 경로를 순간 끊어 값을 지우지 않는지. 시험 안: 시퀀서 릴레이에 대해 R.1에서 오실로스코프로 틈·튐 측정(결정 0001의 측정 2·3과 같이). 필요하면 `CK` 쪽에 RC 또는 C 병렬을 둔다.
2. **코일 전압 여유(6절).** (닫힘, 결정 0003 K5: 보드 단자 23.0 V 이상으로 정한다. 실측 I4에서 최대 부하의 단자 전압 확인.) 급전·OR 다이오드 3–4개를 거치는 마스터·슬레이브 코일이 정격의 80% 이상인지. 전원 장치 하한 21.6 V에서는 약 20 V로 여유가 작다. 대안: 24 V 공급을 26 V대로, 쇼트키 강하가 더 작은 소자, 가장 깊은 레일(a2 `Z2B`)에 계수 자리 가까이 버퍼 릴레이.
3. **레일 전류 분배.** (닫힘, 결정 0003 K7: 클럭 버스를 둘로 나누고 버스 B의 레일을 쌍둥이 주 릴레이가 따로 만든다. 한 버스의 레일·접점이 나르는 것은 유닛 여섯까지다. 11절) `A2B`·`Z2B`·`A1B`·`Z1B`는 공통 보드의 마스터 접점과 다이오드를 거쳐 **모든 유닛**에 나간다. 한 유닛의 a2 자리가 최대 약 80 mA(코일 10개 × 8 mA)를 끌고, 12유닛이면 약 1 A가 공통 사슬 접점 몇 개를 지난다(정격 2 A, 그러나 직렬 접점·전압 강하). 유닛 수가 6을 넘으면 레일마다 버퍼 릴레이 또는 다이오드 OR 뒤 전류 분배가 필요하다.
4. **대형 릴레이 표시.** `concept.md` 5.2절의 "투명 케이스 + 표시등"은 계수기 마스터·슬레이브를 범용 릴레이(최대 20 ms)로 하자는 뜻으로 읽힌다. 이 설계에서 20 ms 릴레이를 쓰면 `CK` 폭이 20 ms를 넘고 한 위치가 늘어난다. 빠른 모드에서는 KS·KM을 신호 릴레이로 하고 표시용 종속 릴레이(투명 케이스, `Q`에서 구동)를 따로 두는 쪽이 낫다(5.2절 마지막 줄의 "표시용 큰 릴레이"와 같은 방법). (2026-11-16: 위치 세 자리 l, m, r은 `POS`를 받는 **위치 표시 보드** `hardware/relay/position-display`가 글자로 보인다. 계수기 보드는 바뀌지 않았다.)
5. **a1을 세지 않는 구간 실습 모드.** `concept.md`는 구간 실습에서 a1을 다이얼 코드로 직접 구동해 13개를 줄일 수 있다고 했다. 이 설계는 a1이 11개이므로 이득이 작다(유닛당 11개). 구간 전용 유닛에서 a1 자리를 생략하고 다이얼 코드(`LOAD`와 무관한 상시 전압)를 a1 `CTRL`에 직접 연결할지 결정.
6. **중계 릴레이 필요성.** a3/a4 중계 10개는 공통 코드선 하나가 유닛마다 접점 하나로 시프터 한 단 전체(26 코일)를 구동하는 것을 피하려는 것이다. 유닛 수가 적으면 공통 슬레이브 접점 두 극 병렬로 직접 구동도 가능(6유닛 약 1.3 A). 유닛 수와 접점 정격으로 정한다.
7. **다이오드 부품 수.** 한 자리 64개(보드당 196/138). 2연·3연 소자, 또는 코일 직렬 쇼트키를 통합하면 줄일 수 있다. 기판 배치 단계에서 정한다.
8. **프리셋 중의 `STROBE`.** (닫힘, 결정 0003 K5·4.4절) HOME 중에는 `CK` = `NCK` = 0이므로 시프터 `CTRL`이 순간적으로 0이 된다(`CTRL` 변경은 무전류여야 함, `design-brief.md` 4.2절). **순서기는 `HOME` 동작 중 `STROBE`·`JUDGE`를 내지 않는다**(무전류 전환을 위해서도). `CLEAR`는 `HOME`의 끝에 한 번 낸다(0003 4.4절 (나), 2026-11-15 개정: 비상 정지가 남긴 감지 릴레이를 지움. `STROBE`가 없어 시험 전류가 없으므로 전환과 무관). 순서기 보드(K7)가 지킨다.
9. **코일 극성 등.** G6S-2 코일 극성·핀 기능(시프터 README 6절 열린 질문 1)과 풋프린트는 시프터 보드와 같은 가정(핀 1 = +, 핀 12 = −)이다.

## 11. 클럭 버스 B와 레일 버퍼 (결정 0003 K7)

### 11.1 무엇이 문제였나

유닛 보드의 a2·a1 자리는 `CK`/`NCK`를 직접 받지 않는다. 받는 것은 공통 보드가 만든 **레일** `A2B`·`Z2B`·`A1B`·`Z1B`이고(3절), 이 레일은 순서기의 `CK`/`NCK`가 공통 보드의 pL·pM 마스터 접점과 다이오드를 지나 나온 것이다. 그러므로 모든 유닛의 계수 코일 전류가 공통 보드 J1의 `NCK`(φ1) 또는 `CK`(φ2) 핀 하나로 들어온다.

- 한 자리에서 레일이 먹이는 코일은 비트마다 슬레이브와 마스터 가운데 하나, 곧 **5개 이하**다(KW는 +24 V에서 먹는다). 코일 200 mW(8.3 mA)로 잡으면 한 자리 ≤ 42 mA, 유닛 하나(a2 + a1) ≤ 83 mA **(계산)**.
- 12유닛이면 유닛 쪽 1.0 A + 공통 네 자리 0.17 A ≈ **1.2 A**가 J1의 한 핀을 지난다. D-sub 핀 하나의 한도 1 A(0003 5.1절 4항)를 넘는다. 이것이 K7의 "레일 버퍼"다.
- 순서기는 그래서 같은 코일로 움직이는 전환 접점 둘로 `CK`/`NCK`/`LOAD`를 **두 버스**로 낸다(J3 `CLK_A` = 공통 보드 + 유닛 1–6, J4 `CLK_B` = 유닛 7–12). 이 절은 둘째 버스를 계수기 쪽에서 받는 방법이다.

### 11.2 왜 `CK_B`를 유닛 7–12로 그냥 넘기면 안 되는가

유닛 7–12가 받아야 하는 것은 `CK_B` 자체가 아니라 **"`CK_B` ∧ (이번 클럭에 a2/a1이 오르는가)"** 다. 이 판정은 pL과 pM의 **마스터 접점 사슬**이 한다(`A1B` = `CK` ∧ l = 25 ∧ m = 25, `A2B` = `CK` ∧ l = 25 ∧ m ≠ 25, `Z?B`는 그 반대). 버스 B의 전류가 버스 A를 지나지 않으려면 같은 판정을 하는 **둘째 접점 사슬**이 필요하다. 마스터 릴레이의 두 극은 이미 다 쓰고 있다(극 1 = 올림 사슬, 극 2 = `Y`).

검토한 다른 길과 버린 이유:

| 안 | 버린 이유 |
|---|---|
| 버스 A의 레일(`A2B` 등)로 릴레이를 움직여 그 접점이 `CK_B`를 잇게 함("레일을 따라가는 버퍼") | 클럭 길에 릴레이 하나(2.5–5 ms)가 더 들어간다. `CK` 폭 8 ms 안에 버퍼 동작 + 슬레이브 동작(최대 5 + 4)이 들어가지 않고, 버퍼가 놓이는 동안 `A`와 `Z` 레일이 함께 켜져 값이 틀어진다(2.5절: 두 상이 겹치면 안 됨) |
| KW(값 ≠ 25) 접점으로 "l = 25"를 읽음 | KW는 **슬레이브** 값을 본다. 슬레이브는 `CK` 동안 바뀌므로(25 → 0) KW가 `CK` 도중에 넘어간다. 마스터가 "미리 계산"으로 `CK` 동안 변하지 않는다는 이 설계의 전제(2.1절)가 깨진다 |
| 유닛 보드에 `CK_B`를 받는 자리를 만듦 | 유닛 보드에는 판정 논리가 없다(3절). 판정을 유닛마다 다시 만들면 유닛마다 릴레이 10개가 는다 |

### 11.3 회로: 쌍둥이 주 릴레이

pL과 pM의 마스터 릴레이마다 **쌍둥이**를 하나씩 둔다(K130–K134, K230–K234, 10개). 쌍둥이의 코일은 짝인 마스터 코일과 **병렬**이다(같은 넷 `MC_i`, 같은 급전 다이오드와 역기전력 다이오드). 따라서 쌍둥이는 언제나 마스터와 같은 값을 갖고, 접점 두 극을 버스 B에 준다. 순서기의 "쌍둥이 릴레이"(접점을 늘리는 것)와 같은 방법이다.

- 쌍둥이 극 1(COM 4, NC 3): 버스 B의 올림 사슬 `AB_i` → `AB_{i+1}`. pL에서는 `CK_B`에서 시작해 끝이 `LC_B`(= `CK_B` ∧ l = 25), pM에서는 `LC_B`에서 시작해 끝이 `A1B_B`. NO(5)는 쓰지 않는다(마스터의 유지는 버스 A의 `G`가 이미 한다).
- 쌍둥이 극 2(COM 9, NO 8): `YB_i` = 그 자리의 `AIN_B` ∧ 마스터 i.
- 다이오드 OR(자리 시트 안): pL `ZL_B` = `NCK_B` ∨ `YB0..4`(D165–D170), pM `Z1B_B` = `ZL_B` ∨ `YB0..4`(D265–D270), pM `A2B_B` = `YB0..4`의 OR(D271–D275). 루트: `Z2B_B` = `ZL_B` ∨ `A1B_B`(D805, D806). 버스 A의 D803·D804와 같은 규칙이다.
- 커넥터: J5 `CLOCK_B`(J1과 같은 배치) → 위 사슬 → J6 `UNIT_BUS_B`(J2와 같은 배치). `LOAD_B`는 J5 3번에서 J6 15번으로 바로 간다(공통 자리는 프리셋 0이라 `LOAD`를 쓰지 않는다). 코드선 `L0–4`·`T0–4`와 0 V는 J2와 같은 넷이다.
- 유닛 보드는 바뀌지 않는다. 유닛 1–6은 J2의 리본, 유닛 7–12는 J6의 리본에 꽂는다. 6유닛 기계에서는 J5·J6을 비워 두며, 쌍둥이 10개와 다이오드 19개는 빼고 조립해도 된다(쌍둥이는 버스 B에만 접점을 준다).
- 공통 보드의 네 자리(pL, pM, a3, pR)와 쌍둥이 코일은 버스 A에서 먹는다.

### 11.4 시간: 두 버스가 어긋날 때 (계산)

순서기의 두 버스 릴레이 KCKA·KCKB는 같은 코일 구동을 받지만 따로 움직이므로 모서리가 어긋난다. 순서기 시뮬레이션(`verify_sequencer.py`의 기본 시나리오, 모드 4 × 시드 6, `CK` 펄스 936개)에서 `CK_B` − `CK_A`는 **오름 −2.86…+2.84 ms, 내림 −2.50…+2.50 ms**, 버스 B의 `CK` 폭은 최소 8.26 ms였다(복귀 1.5–4 ms의 차 = 2.5 ms).

- **오름은 어느 쪽이 먼저여도 된다.** 마스터(와 쌍둥이)는 φ1 동안 이미 정착해 있다(4절: `CK` 하강 뒤 최대 약 18 ms, 주기 63 ms).
- **버스 B가 먼저 내려가도 된다.** 버스 A가 아직 `CK`이면 마스터는 움직이지 않는다(2.3절).
- **버스 B가 늦게 내려가는 경우**가 시간의 문제다. `CK_A`가 끊긴 뒤 마스터가 처음 바뀌는 때는 ① 놓이는 마스터: 유지(`G`)가 끊긴 뒤 역기전력 다이오드로 늘어난 복귀 **3 ms 이상**, ② 붙는 마스터: `NCK_A`가 돌아온 뒤(전환 0.2 ms 이상) 동작 2.5 ms 이상, 곧 **2.7 ms 이상**이다. 쌍둥이는 같은 코일 전압으로 같은 범위에서 움직인다. `CK_B`는 `CK_A`보다 **2.5 ms 이하** 늦게 끊기므로 쌍둥이 사슬은 `CK_B`가 켜져 있는 동안 바뀌지 않는다(최악 모서리에서 여유 0.2 ms).
- 여유가 작아 보이지만 두 번째 벽이 있다: 설령 겹침이 생겨도 그 길이는 (어긋남 − 2.7 ms)로 1 ms보다 훨씬 짧고, 버스 B 유닛의 릴레이를 바꾸려면 동작 2.5 ms 또는 복귀 3 ms 이상 지속되어야 한다. 이 두 값은 R.1에서 잰다(11.6절).
- 넷리스트 시뮬레이션(7절)은 시간이 없는 모델이므로 앞의 두 경우(오름 어느 쪽이든, 내림 B 먼저)를 매 클럭 무작위로 넣어 17,576 클럭을 돌렸고, 셋째 경우는 이 계산으로 보인다.

### 11.5 전류 (계산, 코일 200 mW)

| 버스 | 먹이는 것 | 레일 전류(최대) |
|---|---|---:|
| A (J1, 순서기 J3) | pL·pM(마스터 + 쌍둥이 + 슬레이브 ≤ 10코일씩 = 83 mA씩), a3·pR(≤ 42 mA씩), 유닛 1–6(≤ 83 mA씩) | **0.75 A** |
| B (J5, 순서기 J4) | 유닛 7–12 | **0.50 A** |

- 둘 다 D-sub 핀 한도 1 A와 순서기 레일 PTC 1.1 A 안이다. `CK` 동안 뒤집히는 비트는 잠시 슬레이브와 마스터가 함께 켜지지만 한 자리 6코일을 넘지 않는다.
- 한 리본(J2 또는 J6)의 레일 핀 하나는 유닛 여섯의 한 자리 몫(≤ 0.25 A)을 나른다. 8절 3번의 "유닛이 여섯을 넘으면 공통 사슬 접점에 1 A"는 버스마다 사슬이 따로라 생기지 않는다.
- `LOAD`(프리셋, `HOME` 중 약 25 ms): 유닛 하나에서 다이얼이 1인 비트의 슬레이브(a1·a2 각 최대 4비트 = 8코일, 약 67 mA)를 먹인다. 버스마다 최대 약 0.4 A다. 순서기의 `LOAD` PTC(버스마다 유지 0.1 A)가 이 짧은 펄스에서 트립하지 않는지 품번과 함께 확인해야 한다(11.6절).

### 11.6 남은 것

1. **R.1 측정**: 순서기 KCKA·KCKB의 내림 어긋남(≤ 2.5 ms 가정)과 계수기 마스터의 가장 빠른 변화(≥ 2.7 ms 가정)를 오실로스코프로 함께 잰다. 여유가 없으면 순서기에서 KCKB의 복귀를 KCKA보다 빠르게 하는 쪽(클램프 제너)으로 맞춘다.
2. **`LOAD` PTC**: 순서기의 `LOAD` 버스별 PTC(유지 0.1 A)에 6유닛 프리셋 전류 약 0.4 A가 25 ms 흐른다. 트립 시간 곡선을 품번으로 확인한다 **(미확인)**.
3. 쌍둥이 코일이 마스터 급전 다이오드의 전류를 두 배로 한다(코일 하나 8.3 → 16.6 mA). 쇼트키 강하가 조금 늘어 마스터 코일 전압이 수십 mV 준다 **(추정)**. 6절의 코일 전압 여유(23.0 V 단자에서 정격의 89%)에 비하면 작다.
