## 2. 한 자리의 회로 (11 릴레이)

### 2.1 아이디어

비트마다 **슬레이브 릴레이 KS**(값을 갖고, 접점이 `CTRL`을 구동)와 **마스터 릴레이 KM**(항상 KS의 **반대값**을 따라가는 거울)을 둔다. 한 자리의 증가는 이진 올림 사슬에서 "토글해야 하는 비트"를 가려내고, 그 비트의 슬레이브가 마스터 값을 **한꺼번에** 받는 동작이다: 토글이므로 새 값 = 마스터 값 = 옛 값의 반대. 마스터가 클럭 동안 변하지 않으므로 올림 사슬은 접점만 지나가고 릴레이 동작을 기다리지 않는다(파문 올림이 아니라 순간 전달, 경주 없음).

신호는 모두 24 V "레일"(접점·다이오드를 거쳐 전달되는 +24 V)이고, 증가/정지는 상보 쌍으로 다룬다.

| 이름 | 뜻 |
|---|---|
| `AIN` / `ZIN` | 증가 레일 / 정지 레일 (항상 하나만 켜짐, 클럭 구간에서 `AIN` = 클럭 펄스 ∧ 이 자리의 증가 조건) |
| `AOUT` / `ZOUT` | 올림(25 → 0) 레일 쌍 = 다음 자리의 `AIN` / `ZIN` 재료 |
| `NOUT` | `AIN` ∧ (값 ≠ 25) |
| `P0..P4` | 프리셋 코드(다이얼). 24 V는 `LOAD` 동안에만 걸린다 |
| `Q0..Q4` | 값의 각 비트(1이면 24 V) = `CTRL` |

### 2.2 구성 (비트 i = 0..4)

- **KS_i** (극 1: COM = +24 V, NO → `Q_i`, NC → `NQ_i`; 극 2: COM = 레일 `Z_i`, NC → 마스터 거울, NO → 자기 유지).
- **KM_i** (극 1: COM = 사슬 `A_i`, NC → `A_{i+1}`(사슬 계속), NO → `G_i`(마스터 유지 + 슬레이브 적재 급전); 극 2: COM = `AIN`, NO → `Y_i` = `AIN` ∧ KM_i).
- **KW** (한 자리에 하나): 코일 = `NQ0 ∨ NQ4 ∨ NQ3`(다이오드 OR) = "값 ≠ 25". 접점 두 극이 비트 1, 2의 마스터 거울 경로에 직렬로 들어간다.
- 올림 사슬: `A_0 = AIN`, `A_{i+1} = A_i ∧ (마스터 i = 0)`(마스터 NC 접점) → 비트 i는 `A_i`가 올라올 때 토글. `A_5` = `AOUT`.
- 정지 레일: `Z_t = ZIN ∨ Y_0 ∨ … ∨ Y_{t−1}`(병렬 다이오드 OR, 한 노드에 다이오드 한 개 전압 강하) = `NOT A_t`.
- 슬레이브 코일 급전(다이오드로 OR): ① 자기 유지(레일 `Z_i` → KS 극 2 NO), ② 적재(`A_i` → KM NO = `G_i`, 마스터가 1일 때), ③ 프리셋(`P_i`). 마스터 코일 급전: ① 거울(레일 `Z_i` → KS 극 2 NC; 비트 1, 2는 KW 접점 경유), ② 유지(`G_i`).
- 코일마다 역기전력 다이오드(1N4148W), 급전·OR 다이오드는 쇼트키(1N5819W, 강하 약 0.3 V — 코일 전압 확보). 비트마다 `Q`에 저항 4.7 kΩ + LED(값 표시, 5 mA).

### 2.3 동작 (한 클럭)

클럭은 **두 상**이다. `NCK`(= 평상시 켜짐)와 `CK`(= 확정 펄스). 상보이며 겹치지 않는다(2.5절).

| 상 | 레일 | 마스터 | 슬레이브 |
|---|---|---|---|
| φ1 (`NCK`, 평상시) | 모든 `Z_i`가 켜짐, `A_i` 꺼짐 | 슬레이브의 반대값을 계속 따라감(**미리 계산**) | 자기 유지 |
| φ2 (`CK`, 확정) | `AIN`이 켜진 자리: 토글 비트의 `Z_i`가 꺼지고 `A_i`가 켜짐 | 토글 비트: 자기 유지(`G`)로 값을 붙잡음. 나머지: 계속 거울 | 토글 비트: 마스터 값을 받음. 나머지: 유지 |

- **정지**: `AIN` = 0이면 모든 `A_i` 꺼짐, 모든 슬레이브가 `Z_i`로 유지된다.
- **25 → 0**: 값이 25 = `11001b`일 때 KW가 꺼져 비트 1, 2의 거울이 끊기고(마스터는 `00000`), 이때만 마스터 전부가 0이 된다(정상 값에서 마스터 = NOT 값이 0이 되려면 값 = 31이어야 하므로 도달 불가). 마스터 NC가 모두 닫혀 있으므로 `A_0 … A_4`가 전부 올라와 슬레이브 다섯 개가 모두 0을 받는다. `A_5`가 올라와 **올림 = `AOUT` = `AIN` ∧ 값 = 25**가 된다. 따라서 25 → 0을 별도 감지·리셋 없이(과도 값 26 없이) 같은 사슬이 처리한다.
- 정상 증가에서 `A_{i+1} = A_i ∧ 슬레이브 i`이므로 이진 +1과 같다. 이진 코드 직접 구동이므로 시프터에 중간값이 안 보인다.
- `ZOUT = NOT AOUT`는 정지 레일이 상보를 유지하게 하는 쌍이다(`NCK`가 꺼진 φ2에서도 올림이 없으면 켜짐).

### 2.4 릴레이 수 (concept.md 추정과 비교)

한 자리: KS 5 + KM 5 + KW 1 = **11개**. `concept.md` 5.2절의 "비트당 2개 × 5 + 리셋·올림 2–3개 ≈ 13개"보다 2개 적다(올림은 마스터 접점 사슬이 하고, 26진 처리는 KW 하나다). 대신 다이오드가 한 자리 64개다(급전 25 + 정지 레일 OR 20 + `NOUT` OR 5 + KW 3 + 역기전력 11). 2연 다이오드 소자(SOT-23)를 쓰면 부품 수는 절반 근처로 준다 **(추정)**.

| 유닛 | a2, a1 | 22 | `concept.md`의 26 대비 −4 |

### 2.5 시퀀서에 요구하는 것

- `CK`/`NCK`는 **하나의 전환(c) 접점**에서 나온다(COM = +24 V, NO → `CK`, NC → `NCK`). 개별 릴레이 둘로 만들어 둘 다 켜지면 값이 틀어진다(시뮬레이션에서 확인: "info" 줄). 전환 중 양쪽이 모두 꺼지는 순간(break-before-make)은 릴레이 복귀 시간(3–5 ms, 결정 0001)보다 충분히 짧아야 한다(수 백 µs).
- **HOME(프리셋)**: ① `CK` = `NCK` = 0(전부 꺼짐)으로 모든 릴레이를 풀고, ② `LOAD` = 24 V로 다이얼 공통선에 전압을 걸어 슬레이브가 `P`를 받게 하고, ③ `NCK`를 올리되 **`LOAD`는 그 뒤에 내린다**(겹침 또는 틈 없이). `LOAD`가 `NCK`보다 먼저 내려가는 틈이 릴레이 복귀 시간보다 길면 프리셋이 지워진다(시뮬레이션: 틈 있는 순서는 실패).
- 전원 투입 직후의 릴레이 상태는 임의이며, 위 절차가 어떤 상태에서도 올바른 값을 만든다(무작위 초기 상태로 확인).

## 3. 계수 규칙의 배치 (`relay.rs` `Counters`)

| 계수기 | 증가 조건 | 구현 (`AIN` / `ZIN`) |
|---|---|---|
| pL (a4 = l) | 매 클럭 | `AIN = CK`, `ZIN = NCK` |
| pM | l이 25 → 0 | `AIN = LC` (= pL의 `AOUT`), `ZIN = ZL` (= pL의 `ZOUT`) |
| a3 = l − m | 매 클럭, 단 l이 25 → 0이면 정지 | `AIN = NL` (= pL의 `NOUT` = `CK ∧ l ≠ 25`), `ZIN = NCK ∨ LC` (다이오드 2개) |
| a2 | pM이 증가하고 m이 25 → 0이 아님 | `AIN = A2B` (= pM의 `NOUT` = `CK ∧ l 올림 ∧ m ≠ 25`, pM의 접점 극 2의 COM을 `LC`로 둔 덕분에 다이오드 없이 AND), `ZIN = Z2B = ZL ∨ A1B` (다이오드 2개) |
| a1 | m이 25 → 0 | `AIN = A1B` (= pM의 `AOUT`), `ZIN = Z1B` (= pM의 `ZOUT`) |

- **공통 보드**: 위 다섯 규칙 전부와 pM·a3 자리의 판정이 여기 있다. 유닛으로는 레일 4개(`A2B`, `Z2B`, `A1B`, `Z1B`)와 a4/a3 코드 10선(`L0..4`, `T0..4`)만 나간다.
- **유닛 보드**: 규칙 논리가 **없다**. a2/a1 자리는 공통 레일을 받아 증가/정지만 하고, 프리셋만 유닛별이다(다이얼: a1 = k, a2 = −k mod 26).
- pL·pM·a3의 `P0..P4`는 0 V에 묶어 **프리셋 = 0(clear)**. 오프셋과 무관하게 HOME에서 l = m = 0, a3 = 0이다.
- 모든 올림·판정이 **마스터 값**(φ2 동안 불변)에서 나오므로, 같은 클럭에서 슬레이브가 바뀌어도 규칙 신호가 흔들리지 않는다. 한 클럭의 모든 계수기가 같은 `CK` 펄스 안에서 동시에 움직이고, 사이의 순서(예: pM이 l보다 먼저/나중)가 없다.

## 4. 타이밍 (결정 0001과의 관계)

위치 한 칸(`concept.md` 6절)의 순서: **`CK` 펄스 → 슬레이브 전환 → (a3/a4는 중계 릴레이) → 시프터 전환·바운스 → `STROBE` → 감지 → `JUDGE` → `CLEAR` → `CK` 복귀 → 다음 `CK`**.

| 구간 | 대표 | 최대 | 비고 |
|---|---:|---:|---|
| 슬레이브 동작 (`CK` 상승부터) | 2.5 | 4 | a1, a2는 여기서 `CTRL` 확정 |
| a3/a4 중계 릴레이 | 2.5 | 4 | a3, a4만 해당(슬레이브 + 중계 = 5 / 8 ms). a1, a2는 중계 없이 슬레이브 접점이 시프터 코일을 구동 |
| `CK` 펄스 폭 | | ≥ 4 + 튐 1 = 5 | 슬레이브가 끝까지 움직일 때까지 `CK` 유지 **(계산)** |
| 마스터 재계산 (`CK` 하강부터) | 2.5 | 4 (복귀는 다이오드 포함 최대 10) | 슬레이브가 바뀐 뒤 KW와 마스터가 새 거울을 만든다. **`STROBE`·판정과 겹치는 구간**이므로 위치 시간에 더해지지 않는다 |

- 결정 0001의 표(대표 약 20 ms, 최대 약 33 ms)에서 계수기 항목(릴레이 2단, 대표 5 / 최대 8 ms)과 중계 릴레이(2.5 / 4 ms)는 이 설계에서 a3/a4 경로 = 슬레이브 + 중계(5 / 8 ms)와 a1/a2 경로 = 슬레이브 1단(2.5 / 4 ms)으로 줄어든다. 마스터는 "미리 계산"으로 클럭 경로 밖에 있으므로 클럭 경로에는 **슬레이브 1단**만 있다. 그러므로 표의 두 항목 합(7.5 / 12 ms)이 최악 경로 5 / 8 ms로 줄어 합계는 대표 약 17.5 / 최대 약 29 ms **(계산)**.
- 마스터가 다음 `CK` 전에 정착해야 한다: 슬레이브(4) → KW(4) → 마스터(복귀 최대 10) ≈ 18 ms 최대 **(계산)**. `CK` 하강부터 다음 상승까지 25 ms 목표에서 `CK` 폭 5 ms를 빼면 20 ms가 남아 맞는다. 33 ms 예비안에서도 성립. 이 여유는 R.1에서 실측(항목 2).
- `JUDGE`·`CLEAR`는 테스트 레지스터 쪽 신호이며 계수기와 신호를 주고받지 않는다. 다음 `CK`는 `CLEAR` 뒤에만 나가도록 클럭 시퀀서가 정한다(계수기 보드는 이를 모른다).
- 관찰 모드(≤ 4 위치/초)와 한 스텝 버튼: `CK`를 한 번 누르는 것이 한 클럭이다. 마스터가 자동으로 다음 값을 준비해 두므로 버튼 사이 간격에 제약이 없다.

## 6. 전력과 접점 부하

릴레이 G6S-2급 24 V, 코일 140–200 mW(`concept.md` 4절) **(계산)**: 한 자리에서 슬레이브와 마스터는 비트당 하나씩 켜져 항상 5개 + KW(25 제외 항상 켜짐) = 약 6개 → 0.84–1.2 W, LED 약 0.26 W (값이 평균 44%일 때) → **한 자리 1.1–1.5 W**.

|---|---:|---:|
| 계수 릴레이 | 3.3–4.5 W | 2.2–3.0 W |
| 중계 릴레이 (평균 4.4개) | | 0.6–0.9 W |
| 합계 | **약 3.3–4.5 W** | **약 2.8–3.9 W** (시프터 보드 32–46 W 별도) |

- `CTRL` 접점: a1, a2는 슬레이브 극 1이 시프터 한 단(26 코일 + LED, 약 157–222 mA, 시프터 README 4절)을 직접 구동 — 접점 정격 2 A 안쪽. a3, a4는 중계 릴레이 두 극 병렬(양쪽에서 약 0.22 A).
- 코일 전압 **(계산)**: 가장 깊은 경로는 a2의 마스터 거울(공통 접점 → 다이오드 `Y→Z` → 다이오드 `Z2B` → 다이오드 `Z_t` → 급전 다이오드) 쇼트키 4개 ≈ 1.2–1.6 V. 공급 24 V에서 약 22.6 V, 하한 21.6 V에서 약 20 V이고 동작 전압(정격의 80% = 19.2 V, **미확인**)에 여유가 작다. 열린 질문 2.

## 7. 재생성과 검증

KiCad 10과 Python 3(표준 라이브러리만)이 필요하다. 표준 심볼 위치는 `KICAD_SHARE`(기본 `C:/Program Files/KiCad/10.0/share/kicad`), `kicad-cli`는 PATH 또는 `KICAD_CLI`.

```
python gen_counter.py                                                     # 회로도 재생성
kicad-cli sch erc --severity-all --format json -o erc.json counter_common.kicad_sch   # (counter_unit도 같이)
python verify_counter.py                                                  # 넷리스트 내보내기 + 시뮬레이션 + 음성 시험 (약 1분)
kicad-cli sch export pdf -o counter_common.pdf counter_common.kicad_sch   # PDF는 저장소 밖에 둘 것
```

- **ERC**(KiCad 10.0.4, 모든 심각도): 공통·유닛 두 보드 모두 위반 **0건**(오류 0, 경고 0). 미사용 접점·핀은 `no_connect` 표시. 시트: 공통 루트 + 자리 3장, 유닛 루트 + 자리 2장 + 중계 1장.
- **시뮬레이션** `verify_counter.py`: 두 보드의 계층 넷리스트(kicadsexpr)만 읽고(생성기 지식 없음) 접점 단위로 푼다. 코일은 "+24 V 또는 외부 구동 넷에서 닫힌 접점(양방향)·순방향 다이오드(음극 방향)·고정 배선(케이블, 다이얼)으로 코일 + 핀에 닿는 경로가 있으면 여자"이고(코일·저항·LED는 전도하지 않음, 0 V에 닿으면 단락 오류), 한 입력 벡터마다 릴레이 상태를 고정점까지 반복한다. 자기 유지 경로가 있으므로 상태를 벡터 사이에 이어 간다. 동기 모드(불안정 릴레이 모두 동시 전환)와 비동기 모드(불안정 릴레이 중 무작위 하나씩 전환 = 경주 확인) 둘 다 쓴다.
- **기준 모델**: `relay.rs` `Counters`/`Controls::from_cores`의 **Python 직접 이식**(Rust 호출 아님). 검증기가 먼저 이식본이 크립 오프셋 26종 전체에서 17,577 스텝 내내 `from_cores`와 일치하고 한 바퀴가 HOME으로 돌아옴을 확인한다(Rust 테스트 `counters_track_controls_over_full_run`과 같은 검사).
- **결과**:
  - 구조: 공통 릴레이 33·다이오드 196, 유닛 릴레이 32·다이오드 138, 모든 코일 − 단자가 0 V.
  - 자리 단독(유닛 보드 단독 구동): 프리셋 값 0..25 각각 × 무작위 증가/정지 60 스텝 = 1,560 스텝, 값과 올림 레일(`AOUT` = 증가 ∧ 값 25)이 기대와 일치, 해제 후 안정.
  - HOME 프리셋: 오프셋 26종 전부(무작위 초기 릴레이 상태, 계수 후 재프리셋), 그리고 HOME 절차 변형 4가지(겹침, 직접 전달, 전원 투입에서 시작) 150회. 프리셋 후 `CTRL` = `Counters::home(k)`(a1 = k, a2 = −k mod 26, a3 = a4 = 0).
  - 전체 구동: 공통 1 + 유닛 3(오프셋 3개)을 한 시스템으로 묶어 **17,576 클럭**(+ 시작 상태 확인), 오프셋 **0..25 전부**(9회 × 3유닛, 0·7·25 포함). **매 클럭마다 확정(`CK` 상승 직후)과 해제 후 두 시점**에서 모든 유닛의 시프터 `CTRL` a1..a4가 기준 `Counters`와 같고, 내부 자리(pL = l, pM = m, a3, a2, a1)의 슬레이브값이 기대와 같고 마스터가 "슬레이브의 반대(25에서는 0)"임을 확인. 불일치 0.
  - 경주: 비동기(무작위 순서) 17,576 클럭 + 프리셋 26종, 무작위 초기 상태 — 통과.
  - 음성 시험: 넷리스트 복사본에서 버스선 교환, KS·KM·KW 접점 NC/NO 교환, 다이오드 반전(슬레이브 유지, 올림 OR), 다이얼 비트 교환, 중계 코일 반전, 커넥터 핀 교환 등 14종을 가하면 전부 실패로 잡힌다.
- 한계: 이 시뮬레이션은 **논리·접점 연결 수준**이다. 릴레이 동작·복귀 시간, 튐, 코일 전압 강하(6절), 역기전력 다이오드로 늘어난 복귀 시간은 모사하지 않는다(열린 질문 1–3). 클럭 전환 중 양쪽이 모두 꺼지는 순간은 "릴레이 상태 유지(관성)"로 가정한다.

## 8. 열린 질문

1. **break-before-make 틈과 튐.** `CK`/`NCK` 전환의 틈(양쪽 꺼짐)이 마스터·슬레이브의 복귀 시간보다 충분히 짧은지, `CK` 접점 튐이 마스터 유지 경로를 순간 끊어 값을 지우지 않는지. 시험 안: 시퀀서 릴레이에 대해 R.1에서 오실로스코프로 틈·튐 측정(결정 0001의 측정 2·3과 같이). 필요하면 `CK` 쪽에 RC 또는 C 병렬을 둔다.
2. **코일 전압 여유(6절).** 급전·OR 다이오드 3–4개를 거치는 마스터·슬레이브 코일이 정격의 80% 이상인지. 24 V 하한 21.6 V에서 약 20 V로 여유가 작다. 대안: 24 V 공급을 26 V대로, 쇼트키 강하가 더 작은 소자, 가장 깊은 레일(a2 `Z2B`)에 계수 자리 가까이 버퍼 릴레이.
3. **레일 전류 분배.** `A2B`·`Z2B`·`A1B`·`Z1B`는 공통 보드의 마스터 접점과 다이오드를 거쳐 **모든 유닛**에 나간다. 한 유닛의 a2 자리가 최대 약 80 mA(코일 10개 × 8 mA)를 끌고, 12유닛이면 약 1 A가 공통 사슬 접점 몇 개를 지난다(정격 2 A, 그러나 직렬 접점·전압 강하). 유닛 수가 6을 넘으면 레일마다 버퍼 릴레이 또는 다이오드 OR 뒤 전류 분배가 필요하다.
4. **대형 릴레이 표시.** `concept.md` 5.2절의 "투명 케이스 + 표시등"은 계수기 마스터·슬레이브를 범용 릴레이(최대 20 ms)로 하자는 뜻으로 읽힌다. 이 설계에서 20 ms 릴레이를 쓰면 `CK` 폭이 20 ms를 넘고 한 위치가 늘어난다. 빠른 모드에서는 KS·KM을 신호 릴레이로 하고 표시용 종속 릴레이(투명 케이스, `Q`에서 구동)를 따로 두는 쪽이 낫다(5.2절 마지막 줄의 "표시용 큰 릴레이"와 같은 방법).
5. **a1을 세지 않는 구간 실습 모드.** `concept.md`는 구간 실습에서 a1을 다이얼 코드로 직접 구동해 13개를 줄일 수 있다고 했다. 이 설계는 a1이 11개이므로 이득이 작다(유닛당 11개). 구간 전용 유닛에서 a1 자리를 생략하고 다이얼 코드(`LOAD`와 무관한 상시 전압)를 a1 `CTRL`에 직접 연결할지 결정.
6. **중계 릴레이 필요성.** a3/a4 중계 10개는 공통 코드선 하나가 유닛마다 접점 하나로 시프터 한 단 전체(26 코일)를 구동하는 것을 피하려는 것이다. 유닛 수가 적으면 공통 슬레이브 접점 두 극 병렬로 직접 구동도 가능(6유닛 약 1.3 A). 유닛 수와 접점 정격으로 정한다.
7. **다이오드 부품 수.** 한 자리 64개(보드당 196/138). 2연·3연 소자, 또는 코일 직렬 쇼트키를 통합하면 줄일 수 있다. 기판 배치 단계에서 정한다.
8. **프리셋 중의 `STROBE`.** HOME 중에는 `CK` = `NCK` = 0이므로 시프터 `CTRL`이 순간적으로 0이 된다(`CTRL` 변경은 무전류여야 함, `design-brief.md` 4.2절). 시퀀서가 HOME 중 `STROBE`를 열어 두는지 확인.
9. **코일 극성 등.** G6S-2 코일 극성·핀 기능(시프터 README 6절 열린 질문 1)과 풋프린트는 시프터 보드와 같은 가정(핀 1 = +, 핀 12 = −)이다.

## 9. 기판 배치 (배치만, 배선은 사용자가)

규칙: **PCB = 배치만, 배선 없음**(자동 배선기·외부 다운로드 없음). 생성물에는 외곽선, M3 구멍 4개, 모든 풋프린트의 배치·방향, 회로도 넷리스트에서 가져온 넷(= 래츠네스트), 설계 규칙이 있고 동선(트랙·비아·존)은 하나도 없다. **배선: 사용자가** 한다.

| 보드 | 파일 | 크기 | 부품 | 패드 / 넷 | 래츠네스트 (배선할 연결) |
|---|---|---|---:|---|---:|
| 공통 | `counter_common.kicad_pcb` | **250 × 228 mm** | 261 + 구멍 4 | 750 / 211 | 539 |
| 유닛 | `counter_unit.kicad_pcb` | **250 × 228 mm** | 196 + 구멍 4 | 648 / 203 | 445 |

**크기와 카드 케이지.** 두 장 모두 시프터 보드와 **같은 250 × 228 mm**, 구멍 위치도 같다(모서리에서 5 mm, M3 4개). 따라서 시프터·공통·유닛 보드가 같은 카드 규격으로 케이지 한 슬롯 형식에 들어간다. 이 크기에서 자리 블록이 빽빽하지 않다(공통은 블록 3개 + 규칙 다이오드가 판 면적의 약 50%, 블록 사이 간격 좌우 6 mm·상하 24 mm, 아래쪽 여백 큼). 더 작게 할 수도 있었으나(공통 약 250 × 190) 카드 규격 통일과 배선 여유를 택했다.

**배치 방식.** 한 자리(11 릴레이 + 다이오드 64 + R 5 + LED 5)를 **반복 블록 98 × 84 mm**로 만든다(`gen_counter_pcb.py` `digit_block`, 공통의 pL·pM·a3, 유닛의 a2·a1이 모두 같은 블록).

- 비트 열 5개(피치 16 mm): 위에서부터 슬레이브 KS, 마스터 KM(릴레이는 G6S-2, 회전 없음, 열 사이 6.7 mm 배선 통로), 그 아래 이 열의 다이오드 SOD-123(급전 5, 역기전력 2, 레일 OR, NOUT; 최대 14개, 2열 × 7행, 행 피치 3.8 mm), 맨 아래 표시 저항 + LED.
- 여섯 번째 열: 감김 릴레이 KW와 KW 코일 다이오드 4개.
- 도면 층에 블록 테두리(점선)와 실크 라벨을 그렸다. 블록 안의 위치만 보면 어느 자리·비트인지 읽힌다.
- **공통**: 블록 3개(pL, pM 위 / a3 아래 왼쪽) + 아래 오른쪽에 자리 사이 규칙 다이오드 D801–D804. 커넥터 J1(CLOCK, DE9), J2(UNIT_BUS, DB25)는 **왼쪽 가장자리**(커넥터 선택은 그대로).
- **유닛**: 블록 2개(a2, a1) 위쪽 + 중계 릴레이 10개(K900–K909, 아래 왼쪽, 열마다 역기전력 다이오드). J1(BUS, DB25)과 J2(DIAL, DA15)는 **왼쪽**, J3–J6(CTRL, DE9 × 4)는 **오른쪽 가장자리**(시프터 보드 J5와 같은 방향 규약).
- 배치는 `ref`로 정해지는 결정적 함수이며 UUID도 고정이므로 같은 입력은 항상 같은 파일을 만든다.

**설계 규칙과 넷클래스**(`.kicad_pro`에 병합, 시프터 보드와 같은 방식). 제작 규칙(4층, 일반 제조 사양 **(가정)**): 최소 선폭·간격 0.15 mm, 비아 0.5 / 드릴 0.25 mm, 동박–가장자리 0.3 mm, 구멍 사이 0.25 mm. 넷클래스:

| 클래스 | 선폭 | 비아 | 넷 |
|---|---:|---|---|
| Default (신호) | 0.2 mm | 0.5 / 0.25 | 나머지 전부 |
| Rail (코일·레일) | 0.6 mm | 0.8 / 0.4 | `+24V`, `GND`, `CK`, `NCK`, `LOAD`, 버스 레일 `A?B`·`Z?B`, 올림 `LC`·`ZL`·`NL`·`Z3I`, 코드선 `L?`·`T?`, `CTRL`선 `C?_?`, 자리 안의 `Q?`·`A?`·`Z?`·`AOUT`·`ZOUT`·`NOUT`·`Y?` |

`gen_counter.py`는 `.kicad_pro`를 다시 쓸 때 보드 규칙(`board`, `net_settings`)을 보존한다.

**생성과 검증.**

```
python gen_counter_pcb.py        # counter_common.kicad_pcb, counter_unit.kicad_pcb, 규칙 병합 (표준 라이브러리만; kicad-cli 필요)
python verify_counter_pcb.py     # 약 10초
```

`verify_counter_pcb.py` 결과 (KiCad 10.0.4, 두 보드 모두):
- 회로도 부품이 전부 기판에 있고 풋프린트가 회로도와 같으며(공통 261, 유닛 196, 그 밖에는 구멍 H1–H4뿐) 모두 앞면. 패드별 넷이 회로도 넷리스트와 **정확히 같다**(공통 750 패드, 유닛 648 패드). IPC-D-356의 넷 이름 칸은 14자라 계층 이름이 잘리므로 pcbnew로 읽는다.
- `kicad-cli pcb drc`(코트야드 겹침, 가장자리, 간격, 구멍 등 모든 심각도): **위반 0건**, 보고 항목은 연결 안 된 항목(래츠네스트)뿐. 회로도 일치(`--schematic-parity`)는 누락·넷 충돌 0건(심볼 필드 문구 차이와 구멍 4개 "추가 풋프린트"는 제외).

- 음성 시험: 두 릴레이 패드의 넷 교환, 풋프린트를 뒷면으로 뒤집은 경우를 모두 검출.
- 결정성: 두 번 생성한 파일(`.kicad_pcb`, `.kicad_pro`)이 서로, 그리고 저장소 파일과 바이트 단위로 같다.

**배선: 사용자가.** 남은 일은 배선뿐이다(래츠네스트 539 + 445). 배선 전에 볼 점: 부품 높이·릴레이 장착 방향(시프터 README 6절 열린 질문 1)과 7절 열린 질문 2의 코일 전압 여유(깊은 레일의 선폭·저항), 블록 안 다이오드 열을 레일 OR 위치로 옮길 필요가 생기면 `digit_block` 상수만 바꾸면 된다. 리포트 그림은 `python report/figures/make_pcb_figures.py`(저장소 루트)로 만든다.
