## 1. 무엇인가

릴레이 유닛(`S(a1) W_R S(a2) W_M S(a3) W_L S(−l) + 반사판 + 같은 보드를 거꾸로`)에서 시프터가 아닌 **수동 배선 카드** 두 종류.

| 카드 | 종류 | 내용 | 프로젝트 |
|---|---|---|---|
| **W** (로터) | 8종 (로터 I–VIII 하나씩) | 가는 길 `i → W[i]`, 오는 길 `W[i] → i` (= W⁻¹). 커넥터 4개(J1–J4), 부품은 커넥터와 장착 구멍뿐 | `rotor_I` … `rotor_VIII` |
| **U** (반사판) | 2종 (B, C. 얇은 반사판은 불필요) | 가는 길 `i → R[i]`로 되돌림. 커넥터 2개(J2, J3) | `reflector_B`, `reflector_C` |

배선은 `data/wirings/enigma.txt`에서 생성한다(단일 출처). 카드는 **시프터와 같은 외곽 250 × 228, 같은 구멍 4개, 같은 D-sub 37 풋프린트를 시프터의 J1–J4와 같은 좌표·방향에** 둔다. 층은 2층(수동이라 충분, 4층으로 바꿔도 배치는 같다).

| 파일 | 내용 |
|---|---|
| `gen_cards.py` | 열 개 프로젝트(`.kicad_pro`, `.kicad_sch`)를 생성. 회로도는 평면 한 장(A3) |
| `gen_cards_pcb.py` | 기판 배치 생성(외곽, 구멍, 커넥터, 넷리스트, 실크). 배선 없음 |
| `verify_cards.py` | **유닛 전체 넷리스트 합성 + 스크램블러와의 비교 + 음성 시험**(4절) |
| `verify_cards_pcb.py` | 배치 대 회로도, DRC, 시프터와 같은 자리, 결정성, 음성 시험(5절) |
| `ki_common.py` | KiCad 보조 모듈. `hardware/gear/contact-board/ki_common.py`와 **같은 사본** |

## 2. 규약: 쌓기의 방향 (명시)

**커넥터 이름은 시프터의 J1–J4 자리 이름이고 신호의 방향이 아니다.** 시프터는 J1(가는 길 입력)·J2(오는 길 입력)가 한 변, J3(가는 길 출력)·J4(오는 길 출력)가 맞은편 변이다. 로터 카드와 반사판 카드는 같은 자리에 같은 이름을 쓰되 기능이 다르다.

| 카드 | 커넥터 (자리) | 기능 | 쌓기에서의 변·자리 |
|---|---|---|---|
| W | **J3** (오른쪽 변 h1) | `OUTBOUND_IN` 가는 길 입력 | 아래 h1 |
| W | **J4** (오른쪽 변 h2) | `RETURN_IN` 오는 길 입력 | 아래 h2 |
| W | **J1** (왼쪽 변 h1) | `OUTBOUND_OUT` 가는 길 출력 | 위 h1 |
| W | **J2** (왼쪽 변 h2) | `RETURN_OUT` 오는 길 출력 | 위 h2 |
| U | **J3** | `OUTBOUND_IN` (S4의 가는 길 출구에서 받음) | 아래 h1 |
| U | **J2** | `RETURN_OUT` (S4의 오는 길 입구로 보냄) | 위 h2 |

- **왜 W의 입력이 J3·J4인가.** layout.md 3.2절: S1–S3와 W와 U는 부품면이 **뒤**를 보고, 연결 변이 위와 아래다. 뒤를 보는 카드는 J3·J4 변이 **아래**, J1·J2 변이 **위**다(시프터 S1–S3 표). 신호는 S1에서 S4 쪽으로 가므로 W의 입력은 앞 시프터 S(k)의 **출력 변(J3·J4, 아래)**에서 받고, 출력은 다음 시프터의 **입력 변(J1·J2, 위)**으로 나간다. 그래서 W 입력이 J3·J4(아래), 출력이 J1·J2(위)다. 결과로 **같은 자리의 커넥터끼리 곧게 잇는** 규칙(`S1.J3 – W_R.J3`, `W_R.J1 – S2.J1`, …)이 성립한다.
- **a4(앞을 보는 S4)**는 J1·J2가 아래, J3·J4가 위다. S4는 시프터 기판의 **S4 변형**(`shifter_board_s4.kicad_pcb`, 7절 1번)이다: 신호 배정과 변·자리는 표준과 같고 J1–J4가 뒷면에 거울로 놓여 점퍼 14가닥 모두 양 끝 소켓의 핀 1이 같은 끝에 온다. 가는 길은 위의 J3으로 들어가 아래의 J1로 나온다(`−l`).
- 카드가 쌓기에서 도는 방식(앞 보기/뒤 보기, 변과 자리)은 `verify_cards.py`의 `POSE` 표에 있고, **점퍼 14가닥은 이 표에서 도출한다**: 변·자리마다 앞에서 뒤 순서로 커넥터를 두 개씩 짝지으면 layout.md 3.4절의 표와 정확히 같다(길이 39 ×2, 64 ×2, 25 ×10도 같음). 짝이 없는 끝이 `IN`(S1.J1)·`OUT`(S1.J4) 리드다.

점퍼(핀 n = 핀 n, 37선 1:1):

| 변·자리 | 점퍼 |
|---|---|
| 아래 h1 | S4.J1 – U.J3 · W_L.J3 – S3.J3 · W_M.J3 – S2.J3 · W_R.J3 – S1.J3 |
| 아래 h2 | S4.J2 – W_L.J4 · S3.J4 – W_M.J4 · S2.J4 – W_R.J4 · S1.J4 → `OUT` 리드 |
| 위 h1 | S4.J3 – W_L.J1 · S3.J1 – W_M.J1 · S2.J1 – W_R.J1 · `IN` 리드 → S1.J1 |
| 위 h2 | S4.J4 – U.J2 · W_L.J2 – S3.J2 · W_M.J2 – S2.J2 · W_R.J2 – S1.J2 |

전류의 길: `IN` → S1 → **W_R(J3→J1)** → S2 → W_M → S3 → W_L → S4(J3→J1) → **U(J3→J2)** → S4(J4→J2) → **W_L(J4→J2)** → S3 → W_M → S2 → W_R → S1 → `OUT`.

## 3. 카드의 회로

**W 카드 (로터 N).** 핀 1–26 = 선 A–Z. 가는 길: **J3 핀 i+1 → J1 핀 W[i]+1** (네트 `OW_<입력><출력>`, 예: 로터 I `OW_AE`). 오는 길: **J4 핀 j+1 → J2 핀 W⁻¹[j]+1** (네트 `RW_<입력><출력>`). 즉 오는 길은 같은 와이어링을 거꾸로 읽는다(`relay.rs`의 `backward`). 로터 한 장에 2-핀 네트 52개. W[i]는 enigma.txt의 "입구쪽 → 반사판쪽" 표(코어 오프셋 0)이고, 로터의 회전은 시프터 쪽(`a1…a4`)이 한다. 카드에는 이동 위치·노치가 없다.

**U 카드 (반사판 N).** **J3 핀 i+1 ↔ J2 핀 R[i]+1** (네트 `RF_<입력><출력>`, 26개). 반사판은 고정점 없는 대합(R[R[i]] = i)이므로 카드를 끝에서 끝으로 돌려 꽂아도(J3↔J2) 같은 배선이다(7절 2번).

**공통.** 핀 27–29(0 V 기준선, 0003 5.2절)와 30–37은 어디에도 잇지 않는다(`no_connect`, 점퍼의 27–37 가닥은 양쪽 모두 떠 있다). D-sub 껍데기(풋프린트 패드 `SH`, 커넥터마다 2개)와 장착 구멍 H1–H4(도금 M3)는 `CHASSIS`(0003 7.1절). 이 카드에는 0 V도 전원도 없으므로 `CHASSIS`–0 V의 R6·C1은 시프터에만 있다(`CHASSIS` 넷에 PWR_FLAG 하나, ERC용).

## 4. 유닛 전체 검증 (`verify_cards.py`)

`python verify_cards.py [--samples 50] [--exhaustive "B II IV V" | all] [--quick]` (KiCad 10, christopher 패키지가 든 venv).

합성은 **실제 생성된 넷리스트**로 한다(kicad-cli로 내보낸 `shifter_board`, `rotor_*`, `reflector_*`):

- 시프터 보드 4장 S1–S4(릴레이 130개씩), W 카드 3장(고른 휠 순서), U 카드 1장, 2절의 점퍼 14가닥(핀 n = 핀 n). a4는 점퍼가 만드는 방향(J3로 들어가 J1로 나감)으로 거꾸로 쓴다. 점퍼는 카드 자세 표에서 **도출**하고 layout.md 표와 같은지 확인한다.
- 시프터 단 릴레이는 `Controls::from_cores`의 파이썬 이식으로 설정한다(`a1 = r + k`, `a2 = m − a1`, `a3 = l − m`, S4의 제어 `a4 = l`). 접점은 G6S-2 핀 기능(`verify_shifter.py`와 같음), 연결은 넷 + 닫힌 접점 + 점퍼의 합집합-찾기.
- 각 위치에서 `IN`(S1.J1 핀 i)이 **정확히 `OUT`(S1.J4 핀 s(i))에만** 이어지고(26선 모두, 선끼리·제어 핀과 단락 없음) s가 Enigma 스크램블러와 같음을 확인한다. 기준: christopher의 `Bombe.trace`(한 변 메뉴 A→B, 입력선 w의 출력 = 스크램블러(w), `diagonal_board=False`). `WheelOrder::scrambler`의 파이썬 이식은 같은 위치에서 trace와 교차 확인(불일치 0).
- 카드 단위 검사: 각 W 카드가 enigma.txt의 W와 W⁻¹과 같고(핀 단위, 다른 연결 없음), U가 R과 같고, 27–37이 뜨고, `CHASSIS`가 H1–H4뿐.

## 5. 기판 배치 (`gen_cards_pcb.py`, `verify_cards_pcb.py`)

범위: 외곽, 장착 구멍, 커넥터, 넷리스트(래츠넷), 실크. **배선·비아·존 없음**(사용자가 나중에 함).

- 외곽 250 × 228, 모서리 구멍 4개(5 mm 안쪽, 도금 M3, `CHASSIS`)는 시프터와 같다. 커넥터는 J1·J2 왼쪽 변(회전 270), J3·J4 오른쪽 변(회전 90), 좌표 = 시프터의 값(`J1 (12.74, 22.28)`, `J2 (12.74, 96.29)`, `J3 (237.26, 72.13)`, `J4 (237.26, 146.14)`). U는 J2·J3만 둔다.
- 실크(부품면): 카드 이름, A–Z와 와이어링, 쌓기 방향(부품면이 뒤, IN 변 = 아래 J3·J4, OUT 변 = 위 J1·J2), 커넥터 기능.
- 2층, 설계 규칙은 시프터와 같은 저가 업체 표준(선폭/간격 0.15, 비아 0.5/0.25).

**결과**(`verify_cards_pcb.py`, PASS): 10장 모두 회로도 부품·풋프린트·IPC-D-356 패드 넷이 회로도와 같음(껍데기 패드는 `CHASSIS`), DRC(모든 심각도) **위반 0건**, 연결 안 됨 = 래츠넷(W 63 = 52 + `CHASSIS` 11, U 33 = 26 + 7; pcbnew 개수와 일치), 커넥터·구멍·외곽이 `shifter_board.kicad_pcb`와 좌표·회전·풋프린트까지 같음, 회로도·기판 재생성이 바이트 단위로 같음. 음성 시험 3건(패드 넷 맞바꿈, 커넥터 1 mm 이동, 외곽 1 mm) 검출. 점퍼 14가닥과 리드의 **핀 1 정렬**을 풋프린트 자세에서 검사한다(S4는 `shifter_board_s4.kicad_pcb`; 전부 일치, 표준 시프터를 S4로 쓰면 4가닥 어긋남이 정보로 출력됨).

재생성: `python gen_cards.py && python gen_cards_pcb.py && python verify_cards.py && python verify_cards_pcb.py`. 보고서 그림은 `report/figures/make_schematic_figures.py`, `make_pcb_figures.py`(이 폴더의 카드 열 장이 목록에 있음).

## 6. 이 폴더가 확정한 것 (layout.md의 열린 질문에 대한 답)

- W·U 카드는 시프터의 외곽과 J1–J4 자리를 그대로 쓰되 W는 입력이 J3·J4, 출력이 J1·J2다(2절). layout.md 3.2절 표의 "W: 가는 길 입력(h1)…" 은 이 이름에 대응한다.
- U는 커넥터 둘(J3 = 가는 길 입력, J2 = 오는 길 출력)이면 된다.
- 로터 카드는 슬롯(W_L·W_M·W_R)에 무관하게 같은 카드다(슬롯마다 점퍼만 다름). 카드를 바꿔 끼워도 시프터 제어값은 그대로이며 휠 순서는 카드 선택으로만 정해진다.

## 7. 열린 질문

1. **핀 1의 끝 (닫힘: S4 변형 기판).** 표준 시프터 기판으로는 앞을 보는 S4의 점퍼 4가닥(S4.J1–U.J3, S4.J2–W_L.J4, S4.J3–W_L.J1, S4.J4–U.J2)이 양 끝 소켓의 핀 1이 반대 끝에 왔다(S1–S3·W·U의 10가닥은 맞음). D-sub는 키가 있어 리본을 뒤집을 수 없고 거울 점퍼는 핀 대응 표가 필요하므로, **S4 전용 기판 변형**으로 닫았다: `shifter-board/gen_shifter_pcb.py --variant s4` → `shifter_board_s4.kicad_pcb`(같은 회로도·넷리스트, 외곽·구멍·릴레이 배치 그대로, 실크 `S4 / a4 - FRONT`). J1–J4만 **뒷면(B.Cu)에 거울로** 놓아 핀 1이 커넥터의 반대 끝에 온다(핀 행의 중심과 변은 그대로). 앞을 보는 카드는 같은 변·같은 회전이면 핀 1의 끝이 정해져 있어 평면 회전으로는 바꿀 수 없고 뒷면 거울만이 핀 1을 돌린다. 부수 효과: S4의 소켓이 다른 카드처럼 뒤를 향해 S4 점퍼가 39 → 25, 64 → 50 mm가 된다(앞면 쪽 +14가 없음). `verify_cards.py`가 14가닥 + 리드 2의 핀 1 정렬을 기판 파일의 풋프린트 자세에서 검사하고(전부 일치), 표준 시프터를 S4로 쓰는 옛 구성은 4가닥 어긋남으로 검출되는 음성 시험이다. 남은 확인: R.1 시제품에서 실제 압접 소켓의 핀 1 표시(리본의 줄무늬) 방향. **대안 "표준 기판 + J1–J4를 뒷면에서 납땜"은 기각**: 핀 1 정렬은 맞지만 뒷면 커넥터의 핀 k가 표준 구멍 σ(k)(1–19: 20−k, 20–37: 57−k)에 들어가 선 A–S가 거꾸로, T–Z가 끊긴다. `verify_cards.py`의 `back_assembled_study`가 앞·뒤 방향 모두 0건 일치로 확인(`shifter-board/README.md` 6.2절).
2. **U 카드는 끝에서 끝으로 돌려 꽂아도 같다**(반사판은 대합). 시험으로 검출되지 않는 것은 결함이 아니다. W 카드는 돌려 꽂으면 W와 W⁻¹이 바뀌어 검출된다(음성 시험).
3. **층 수.** 수동 카드라 2층으로 두었다. 선 26개 × 2 반쪽의 순열 교차가 약 200 mm 간격에 걸쳐 있어 2층 배선이 가능하리라 보지만(추정, 비아 사용), 배선하면서 4층(시프터와 같은 층 구성)이 필요하면 `gen_cards_pcb.py`의 `four_layers`만 바꾸면 된다. 카드 높이를 228보다 줄일 수 있으나(layout.md) 요청대로 시프터 외곽 그대로 둠.
4. **점퍼 길이·소켓 방향.** layout.md의 25/39/64 길이는 도출된 점퍼와 같다. 압접 소켓의 줄 순서와 리본 방향(1번)은 R.1에서 확인.
5. **얇은 반사판**(B-THIN, C-THIN)과 그리스 휠은 만들지 않았다(M4 전용). `gen_cards.py`의 `REFLECTORS`에 이름을 더하면 같은 생성기로 나온다.
6. **카드 식별 (닫힘: 카트리지 방식, 8절).** W 카드에는 실크(카드 이름, 와이어링)만 있고 코딩 키는 없다: W 카드는 운영자용으로 남는다(R.1, 펼친 유닛, 시운전). 관람객이 다루는 카트리지는 지름이 다른 위치 핀 둘(Ø4·Ø3, 중심선에서 반대쪽으로 1)로 바른 방향만 들어가고, 어떤 로터든 어느 자리에나 들어간다(순서는 관람객이 고름). 로터의 종류는 하우징의 색(기어식 드럼과 같은 색)과 숫자로 가린다.
7. **시험 편의.** 점퍼를 하나씩 시험기로 옮겨 카드를 좁히는 절차(layout.md)는 W·U 카드에 시험점이 없어 커넥터에서 한다. 시험점 필요 여부는 R.1 후.

## 8. 카트리지 방식: 관람객이 바꾸는 로터 (2026-11-16)

결정·이유·인터록·기어식의 짝은 `hardware/common/rotor-cartridge.md`. 여기에는 회로와 기판, 검증만 적는다.

**구성.** 겹침의 W 자리 셋을 비우고, W로 가던 점퍼 12가닥을 같은 시프터 커넥터에서 시작하는 1:1 리드로 늘려 로터 띠의 **받침 기판**(`rotor_socket`, 유닛마다 하나)에 꽂는다. 받침 기판의 자리(L, M, R)마다 스프링 핀 104 + 검출 2가 있고, 관람객이 **카트리지**(`cart_I` … `cart_VIII`)를 꽂으면 자리 + 카트리지가 W 카드 한 장과 같은 회로가 된다.

| 프로젝트 | 내용 |
|---|---|
| `rotor_socket` | 116 × 166, 4층. 앞면: 자리마다 스프링 핀 `<자리><무리><행>`(무리 `OI`, `OO`, `RO`, `RI` × 26) + 검출 `<자리>DT1/2`, 위치 핀 구멍 NPTH Ø4.0 / Ø3.0. 뒷면: D-sub 37 수 12개(J1–J12, 세로, 자리 b의 J(4b+n) = W.Jn), 2극 XH 넷(J13–J15 덮개 스위치, J16 고리 입출력), M3 넷(`CHASSIS`) |
| `cart_<로터>` | 34 × 118, 4층. 뒷면 패드 `OI1..26`, `OO1..26`, `RO1..26`, `RI1..26`, `DT1/2`. 넷은 W 카드와 같다: `OI`(i+1) – `OO`(W[i]+1) = `OW_..`, `RI`(j+1) – `RO`(W⁻¹[j]+1) = `RW_..`, `DT1`–`DT2` = `DET`. 키 구멍 NPTH Ø4.05 / Ø3.05, 하우징 나사 Ø2.7 둘 |

| 파일 | 내용 |
|---|---|
| `gen_cartridge.py` | 회로도 아홉 장과 풋프린트 둘(`Christopher.pretty`: `SpringPin_SMD_D1.6_P2.54`, `CartridgePad_D1.8`, 패드 지름은 **가정**), `fp-lib-table`. 기하 상수(자리의 기준, 패드 격자, 위치 핀, D-sub 자리)의 단일 출처. kicad-cli는 작업 폴더의 복사본에서 돌린다(`stage`, `export_netlist`, `staged_pad_nets`, `staged_drc`: 시간 제한 120초 + 재시도 3회. 동기화 폴더 안에서 직접 돌리면 가끔 끝나지 않고 잠금 파일을 남겼다). `verify_cards.py`와 `verify_cards_pcb.py`도 이제 이 복사본을 쓴다 |
| `gen_cartridge_pcb.py` | 기판 배치(배선·비아·존 없음) |
| `verify_cards.py` | 7번 단계 "CARTRIDGE ARRANGEMENT"(아래) |
| `verify_cartridge_pcb.py` | 아홉 기판: ERC, 배치 대 회로도, DRC, 면, 결정성, 키와 맞물림, 음성 시험 |

**맞물림의 도출.** 받침 기판 파일에서 자리마다 두 위치 핀 구멍의 가운데를 기준으로 핀의 자리를, 카트리지 기판 파일에서 외곽의 가운데를 기준으로 패드와 키 구멍의 자리를 읽는다. 카트리지를 네 축 방향(그대로, 180°, 좌우·위아래 뒤집음)으로 놓아 보아 두 위치 핀이 모두 같거나 큰 구멍에 들어가는 평행 이동을 찾고, 그대로 놓였을 때 핀 106개가 같은 이름의 패드와 0.3 안에서 만나는지 본다. 합성 유닛의 맞물림(핀 노드 ↔ 패드 노드)도 이 도출에서 나온다. 뒤집힌 카트리지는 패드가 바깥을 보므로 연결이 없다.
