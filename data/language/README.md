# German letter-bigram table

`german_bigrams.txt` is a 26x26 table of German letter-bigram counts (rows = first letter A..Z, columns = second letter A..Z), used to score Enigma decryption candidates in Project Christopher.

- Source texts: Johann Wolfgang von Goethe, *Die Wahlverwandtschaften*; Theodor Fontane, *Effi Briest*; Franz Kafka, *Der Prozess: Roman*. All from Project Gutenberg (plain-text UTF-8), listed in the file header with URLs.
- Total: 2,823,722 letters counted across both passes (2,823,716 adjacent pairs).
- Licence: public domain. The texts are public-domain German literature, distributed by Project Gutenberg under its public-domain eBook terms.
- Preprocessing: Gutenberg licence header/footer removed; uppercased; Ä/Ö/Ü to AE/OE/UE, ß to SS.
- The table is the SUM of two passes over the same texts. Pass 1 drops all non-letters so words run together. Pass 2 turns each run of non-letters between two letters into a single X, matching the X word separator in German military Enigma texts. Adjacent pairs are counted within each text per pass.
- Generated by `make_bigrams.py` in this folder (Python standard library only): `python -I make_bigrams.py --x-separators TEXT1.txt TEXT2.txt ... > german_bigrams.txt` (omit `--x-separators` for pass 1 alone).
