# 거짓 정지 수 vs 메뉴 형태

생성: `cargo run --release -p christopher-core --example stop_statistics 400` (2026-11-14, 24스레드, 약 40초).
무작위 연결 메뉴(지정한 글자 수·루프 수)를 무작위 Enigma I 로터 순서 하나에 걸어 17,576 위치 전체를 구동한 정지 수의 평균.
정답 키가 없는 메뉴이므로 모든 정지는 거짓 정지다.

튜링의 추정(12글자 메뉴, 로터 순서당, 2차 자료 경유 — `docs/reference/bombe-mechanics.md` 9절): 루프 0/1/2/3개 → 820 / 31 / 1.2 / 0.04.
측정값(12글자, 대각선 보드): 673 / 25.3 / 0.88 / 0.03. 루프 하나당 약 1/26로 줄어드는 비율이 일치하고, 절대값은 추정치의 약 0.8배.
대각선 보드가 없으면 루프 0–1개에서 사실상 모든 위치가 정지한다(웰치먼 개량의 효과).
