# 4로터 봄베와 릴레이식 봄베 참고 노트

조사일: 2026-11-14 · 대상: PLAN.md 7절 중 "미 해군 4로터 봄베", "영국식 4로터 변형", "미 육군 릴레이식 봄베" · 인용 키는 `report/references.bib` 참조

**출처에 대한 주의.**

- 미 해군 봄베의 완성형 수치(대수, 속도, 치수)는 대부분 Wilcox(NSA)와 Wenger(1945)에서 나온다. 두 문서 모두 **직접 열람하지 못했고**(NSA·국방부 사이트가 접근을 거부), Ekhall·Hallenberg 논문과 Wikipedia의 인용을 거쳐 옮겼다. 해당 항목은 "간접"으로 표시했다.
- Desch 메모(1942-09)와 튜링의 NCR 방문 보고(1942-12)는 1차 자료지만 **설계 단계** 문서다. 완성형과 다른 부분이 있다.
- 미 육군 봄베는 Dermot Turing의 논문이 유일하게 읽은 상세 자료이며, 릴레이 회로도 수준의 정보는 없다.

## 1. 미 해군 4로터 봄베 (NCR, Desch)

### 1.1 요약

| 항목 | 값 | 출처 |
|---|---|---|
| 제작 | National Cash Register(NCR), Dayton, Ohio. 설계 책임 Joseph Desch | [@desch1942memo; @cryptomuseum-bombe] |
| 승인 | 1942-09-04 (Wenger의 1942-09-03 요청) | [@wenger1944history] |
| 시제기 | 1943-05에 2대 가동, 양산형 설계 완료 1943-04, 양산기 가동 1943-06 초 | [@wenger1944history] |
| 유닛 수 | 4휠 에니그마 등가 **16개**(전면 8, 후면 8). 기종 N-530, N-1530. 2대를 합친 N-800(32유닛)도 소수 | [@ekhall-hallenberg2018; @desch1942memo, 편집자 주 8] |
| 휠 수 | 기계당 64개(16 × 4). 네 자리 모두 같은 크기의 휠 | [@wenger1944history] |
| 대수 | 1944-05-30 현재 Laboratory Building에 96대(그중 2대는 2연장), 추가 50대 요청 상태. 최종 121대(간접) | [@wenger1944history; @ekhall-hallenberg2018] |
| 속도 | 가장 빠른 휠 약 1,725 rpm, 초당 약 750위치 (간접) | [@ekhall-hallenberg2018] |
| 구동 시간 | 4휠 1회 약 20분, 3휠 1회 약 50초 (간접) | [@ekhall-hallenberg2018; @wikipedia-bombe] |
| 치수·무게 | 폭 10 ft, 높이 7 ft, 깊이 2 ft, 2.5톤 (간접) | [@wikipedia-bombe] |
| 현존 | 1대 (National Cryptologic Museum) | [@ekhall-hallenberg2018] |

- **대수 불일치.** Wilcox 계열은 121대, TNMOC는 "미국이 145대 제작(주로 4휠 해군형)"이라고 쓴다 [@jackson-bh13; @jackson-bh14]. 1944년 메모의 "96대 + 추가 50대 요청"과 맞춰 보면 145는 계획 수량을 포함한 값일 가능성이 있으나 확인하지 못했다. Cryptomuseum은 "1943년 12월까지 120대 설치"라고 쓰는데 [@cryptomuseum-bombe], 1944-05-30에 96대라는 1차 자료와 어긋난다.
- 1,725 rpm × 26 / 60 ≈ 748위치/초로 "초당 약 750"과 일치한다. 26⁴ = 456,976위치를 750/초로 나누면 약 10분이므로, "약 20분"에는 정지·되감기·검사·자리올림 시간이 포함된 것으로 보인다(이 노트의 계산).

### 1.2 영국 봄베와의 차이

| 항목 | 영국 3로터 봄베 | 미 해군 봄베 | 출처 |
|---|---|---|---|
| 메뉴 설정 | 뒷면에서 26선 케이블("Jones plug") 배선 + commons | **스위치**: 유닛마다 26단 회전 스위치 2개(입력 글자, 출력 글자)가 대각선 보드 행을 선택. 전면에 32개. 별도 commons 불필요 | [@turing1942ncr, (B); @ekhall-hallenberg2018] |
| 대각선 보드 | 뱅크당 1개(3개) | 1개. 모든 유닛이 스위치를 거쳐 여기에 붙음 | [@ekhall-hallenberg2018] |
| 동시 메뉴 | 최대 3벌 | 1벌. 입력 스위치 PRI, SEC 2개(분리된 그래프 2개까지) | [@ekhall-hallenberg2018] |
| 정지 감지 | 감지 릴레이 | 전자식. "cold point test": 입력 글자 노드 26선 중 전류가 닿지 않는 선이 있으면 정지(26입력 AND에 해당하는 Rossi 회로). 사이러트론 사용 | [@ekhall-hallenberg2018; @desch1942memo] |
| 정지 뒤 | 조작자가 읽고 체킹 머신으로 | **자동**: 관성으로 지나친 뒤 역회전해 정지 위치로 복귀 → "hot point test"(입력 노드의 선에 차례로 전압을 걸어 스테커를 구하고 모순이면 기각) → 통과 시 인쇄 → 자동 재시작 | [@turing1942ncr, (A); @desch1942memo, 원문 pp.4–6; @ekhall-hallenberg2018] |
| 출력 | 지시 드럼 + 릴레이 지시기 | 프린터: 휠 위치와 스테커 쌍(숫자 표기로 추정). 프린터 케이블을 메뉴 글자의 대각선 보드 소켓에 연결 | [@ekhall-hallenberg2018] |
| 감지 중 접점 | 좁은 브러시, 회로 차단기로 "깨끗한 접촉" 구간에만 통전 | 넓은 브러시가 인접 세그먼트를 **단락**하며 넘어감. 회로 차단기 불필요 | [@turing1942ncr, (E); @desch1942memo, 원문 pp.7–8] |
| 구동 | 같은 속도의 휠은 기계적으로 직결, 단 사이는 carry 기구 | 단마다 독립 기어열. 빠른 휠은 1:1 베벨 기어, 다음 단은 웜 기어 | [@turing1942ncr, (D); @desch1942memo, 원문 pp.5–6] |
| 로터 순서 변경 | 드럼 교체 | 휠 교체 (15–30분 예상) | [@desch1942memo] |

- 후속 수작업: 인쇄된 정지는 M-9 체킹 머신(스텝 없는 간이 에니그마)으로 나머지 스테커를 확인하고, 이어서 시행착오로 링 설정을 맞춘다 [@ekhall-hallenberg2018].
- 시뮬레이션 사례: 13글자 크립에서 456,976위치 중 정지 188회, hot point test 통과는 1회 [@ekhall-hallenberg2018].

### 1.3 휠과 브러시 (설계 단계 메모 기준)

| 항목 | 값 | 출처 |
|---|---|---|
| 휠 배선 | 휠마다 배선 2벌(양단 스크램블러). 뒷면에 동심원 4줄 × 26 = 104 세그먼트 | [@desch1942memo, 원문 p.7] |
| 브러시 | 휠당 104개. 고정측(기계 쪽) 브러시 홀더에 꽂는 교체형 카트리지 | 같은 곳 |
| 재질(계획) | 휠: 베이클라이트 성형 + 경질 구리 또는 내마모 합금 세그먼트. 브러시: 흑연화 구리. 목표 수명 1,000시간(빠른 휠 기준) | 같은 곳 |
| 휠 축 | 스플라인. 모터 없이 영점 복귀·임의 위치 설정 가능. 휠을 자리끼리 바꿔 마모 분산 | 같은 곳 |
| 초기 계획 속도 | 빠른 휠 3,400 rpm(초당 56회전) | [@desch1942memo, 원문 pp.2–5] |
| 빠른 휠과 둘째 휠 | 웜 기어 약 37:1. 둘째 휠이 1/26 회전하는 동안 빠른 휠 약 1.4회전("creeping transfer"). 여분 0.4회전은 둘째 휠 브러시가 세그먼트 틈을 넘는 시간 | [@desch1942memo, 원문 pp.5–6] |
| 셋째·넷째 휠 | 클러치식 간헐 전송, 전송당 약 0.2초. 전송 중 cold point 검출기 정지 | [@desch1942memo, 원문 p.3, p.6] |

- 영국 봄베와 **브러시 위치가 반대**라는 점에 주의: 영국은 드럼에 브러시, 기계에 접점. Desch 계획은 휠에 세그먼트, 기계에 브러시.
- 초기에는 자리마다 휠 크기가 달랐으나(빠른 자리에 작은 휠), 휠 총수가 약 4만 개로 늘고 정비가 어려워져 네 자리 공용 단일 크기로 바꿨다 [@wenger1944history; @turing1942ncr, (C)].
- 가장 어려웠던 부품은 고속 정류자(commutator)였다 [@wenger1944history].
- 원래 계획은 휠 오더 336개마다 1대씩 336대였다가 96대로 줄었다 [@wenger1944history].

### 1.4 휠과 에니그마 로터의 대응, 속도 순서

- Ekhall·Hallenberg의 추론: 위 휠이 반사판 플러그에 연결되므로 에니그마 왼쪽(반사판 쪽) 로터, 아래 휠이 오른쪽 로터에 대응한다 [@ekhall-hallenberg2018, 3.3절].
- 튜링의 보고(1942-12, 제안 단계): "B-휠(4번째 로터 = 그리스 로터)을 가장 느리게 해 3휠 문제에도 쓸 수 있게 한다. **L.H.W.가 super-fast, M.W.가 fast, R.H.W.가 medium**" [@turing1942ncr, (H)]. 즉 영국 봄베와 마찬가지로 에니그마 왼쪽 로터를 가장 빨리 돌린다. 이 배치로는 hoppity를 할 수 없다고 튜링이 지적한다.
- Desch 메모(1942-09)는 "빠른 휠의 변위가 원래 기계의 빠른 휠의 연속 위치를 모사한다고 본다"고 쓰는데 [@desch1942memo, 원문 p.6], 메뉴 오프셋에 대한 이해를 적은 것인지 속도 배치를 적은 것인지 불분명하다. 3개월 뒤 튜링의 보고와 문면상 어긋난다.
- 3휠 모드: 가장 느린 휠을 세워 둔다 [@ekhall-hallenberg2018]. 어느 휠이 서는지에 대해 2018년 논문은 아래 휠, 같은 시뮬레이터의 2022년 설명서는 위 휠이라고 쓰고 서로 다르다고 각주에 밝힌다 [@mccarthy2022fourwheel, p.3]. **미해결.**
- 3휠 문제를 4휠 봄베로 풀 때: 4번째 자리에 더미 휠 + 반사판 B/C, 또는 Beta + 얇은 B(= B), Gamma + 얇은 C(= C) [@mccarthy2022fourwheel, p.12]. 4번째 로터는 암호화 중 움직이지 않으므로 "반사판 26종 중 하나를 고르는 선택기"로 볼 수 있다 [@cryptomuseum-bombe].

### 1.5 운용

- 1944년 전반 6개월간 해군 봄베 시간의 약 45%는 영국이 요청한 비해군(육·공군) 문제에 쓰였다 [@wenger1944history].
- 4휠은 탐색 공간이 26배이므로 "26배 많은 봄베 또는 26배 빠른 봄베"가 필요하다는 것이 고속 설계의 출발점이다 [@wenger1944history].

## 2. 영국식 4로터 변형

| 이름 | 구성 | 4번째 휠과 감지 | 대수 | 출처 |
|---|---|---|---|---|
| High Speed Keen | BTM 기본 기계의 고속판. 주력 영국 4휠기 | 오른쪽 끝에 초고속 휠 36개 추가 | 57 | [@jackson-bh12; @jackson-bh14] |
| Cobra | BTM 3휠 봄베 + Mawdsley(Dursley) 제작 유닛 + Flowers/GPO 감지 유닛 | 정류자와 **탄소 브러시**가 4번째 초고속 휠 역할. **진공관** 감지. 탄소 분진과 소음 때문에 벽 너머에 두고 구멍으로 케이블 연결 | 12 | [@jackson-bh12; @jackson-bh14] |
| WW | Wynn-Williams가 고안한 GPO판 초기 4휠 봄베의 부착 장치를 단 BTM 봄베 | (상세 미확인) | — | [@jackson-bh12] |
| BTM 4번째 휠 부착 장치 | 바퀴 달린 독립 유닛, 동력 없음 | 초고속 드럼 36개(4 × 9)를 메뉴에 추가 연결 | — | [@jackson-bh12] |

관련 3휠 변형과 특수기 [@jackson-bh12]:

| 이름 | 내용 |
|---|---|
| Jumbo | 약한 메뉴용 3휠기. 지시 드럼 대신 전동 타자기로 정지를 기록. 유니셀렉터가 정보를 한 글자씩 읽어 내는 소리 때문에 그 과정을 "machine gun"이라 불렀다 |
| Ogre | 봄베 2대를 합친 것. 반사판 D용 |
| Giant | High Speed Keen 4대를 거더에 묶어 한 대처럼 운용. 반사판 D 배선 탐색용. Letchworth에서 1944-06경부터 1945 초까지 |

- **미 해군형과의 구조 차이.** 영국 4휠기는 기존 3휠 봄베(36유닛, 케이블 배선, 릴레이 감지)에 초고속 4번째 휠을 **덧붙인** 구조다. 미 해군형은 16유닛, 스위치식 메뉴, 전자식 감지와 자동 검사·인쇄를 갖춘 새 설계다.
- **이름 혼선: "Mammoth".** Wikipedia는 Keen이 설계한 4휠 봄베(36유닛, 고속 릴레이 감지, 57대)를 "Mammoth"라고 부른다 [@wikipedia-bombe]. 반면 튜링 보고서의 편집자(Erskine·Marks·Weierud)는 "Mammoth는 여전히 정체가 불분명한 장치로, 다수의 릴레이로 스테커 가설을 즉시 기각·확인하는 조합식 검사 장치였던 듯하다"고 적고 [@turing1942ncr, 편집자 주 6], 튜링 본문도 "기계를 Mammoth로 만들면 정지·검사 기능이 더 …"라며 **검사 기능**의 이름처럼 쓴다. TNMOC는 57대짜리를 "High Speed Keen"이라 부르고 Mammoth라는 이름을 쓰지 않는다 [@jackson-bh12]. 이 노트에서는 57대 기종을 High Speed Keen으로 부르고, Mammoth는 불확실한 명칭으로 남긴다.
- **성능.** 1944-05 시점 미 해군 측 기록: 영국은 4휠 봄베를 18대만 만들었고 평균 3대가 가동 중. 1944-03-24 영국 측 전문: "우리 기계의 성능은 여전히 나쁘고 계속 그럴 것 같다. … 신형 3휠 기계 생산을 우선한다" [@wenger1944history]. Cobra는 신뢰성이 낮았다(Wikipedia가 Budiansky를 인용, 간접) [@wikipedia-bombe].
- **확인하지 못한 것:** 영국 4휠기의 4번째 휠 회전수와 1회 구동 시간, High Speed Keen의 감지 방식 상세, WW 부착 장치의 구조.
- 1차 자료 단서: 6812 보고서는 반사판 D 대응의 두 번째 방안으로 "플러그식 U/W를 단 4휠 기계. 메뉴 하나에 16일"을 언급한다 [@us6812report1944, p.39]. 체킹 머신은 드럼 자리 4개로 육·해·공군 어느 작업에도 쓸 수 있었다 [@us6812report1944, p.74].

| M 유닛 | 시연용 1개가 높이 3 m, 폭 2 m, 깊이 50 cm. 완성기는 72개 | [@dturing2021army] |
| 제어 | 제어반("control turret")에서 메뉴 설정·로터 선택. 제어 스테이션 12개가 플러그보드로 유닛을 배분(간접) | [@dturing2021army; @wikipedia-bombe] |
| 구동 시간 | 1회 7분(영국 봄베 약 12분과 비교). Wenger(1945)는 약 10분(간접) | [@dturing2021army; @wikipedia-bombe] |
| 로터 순서 변경 | 30초(누름 버튼). 회전식 봄베는 10분 | [@dturing2021army] |
| 설치 | Arlington Hall | [@dturing2021army] |
| 튜링의 시찰 | 1943-02-05, M 유닛 1개와 에니그마 에뮬레이터. 보고서 1943-02-11 (TNA HW 62/5) | [@dturing2021army] |

- **수치 불일치.** Dermot Turing은 "M 유닛 72개", "프레임 144개"를 따로 쓰고, Wikipedia(Wenger 인용)는 "봄베 10대에 에니그마 등가 144개"라고 쓴다. M 유닛 하나가 에니그마 등가 2개를 맡는지(72 × 2 = 144)는 출처에 명시가 없다. 구동 시간도 7분과 10분으로 갈린다.

### 3.2 로터 치환과 위치 진행의 구현

Dermot Turing 논문 2.1절의 서술을 옮긴다 [@dturing2021army]. 회로도는 실려 있지 않다.

1. **회전 드럼을 스위칭으로 대체.** 설계 목표는 마모되고 정밀 가공이 필요하며 속도를 제한하는 회전 부품을 없애는 것이다. 부품은 전부 표준 전화 교환기용 릴레이다.
2. **로터 = 고정 배선.** 에니그마 로터의 내부 배선을 모사한 고정 배선 회로("rotor emulator", 랙에 장착)가 있다.
3. **위치 = 진입 접점의 선택.** "M 유닛"("Multiple Paths")이 전류를 고정 배선의 어느 진입 접점으로 보낼지 정한다. 로터의 각 진입 접점이 **차례로** 연결되도록 진행시키고, 가운데·느린 로터의 스테핑 패턴을 따라 하는 스위칭이 붙는다.
4. **연속 전압 대신 펄스.** 영국·해군 봄베의 상시 전압 대신 전기 펄스를 쓴다. 펄스 하나가 (a) 튜링의 논리 시험 회로를 흐르고 (b) M 유닛의 릴레이를 동작시켜 **다음 펄스의 경로를 바꾼다.** 즉 시험과 위치 진행이 같은 펄스로 구동된다.
5. **메뉴 오프셋.** 크립 위치에 따른 유닛별 오프셋은 드럼을 돌려 맞추는 대신 M 유닛의 스위칭 진행을 그만큼 앞당겨 준다.
6. **진행 = 3진법 "비즈네르 슬라이드".** 튜링의 표현으로 진행은 본질적으로 "Vigenère slide"이며 3진 전기 산술로 구현된다. 릴레이 **3쌍(6개)을 직렬**로 두고, 닫힌 릴레이들의 가산 효과로 에니그마 에뮬레이터의 연결 지점이 정해진다.

| 릴레이 쌍 | 둘 다 열림 | 하나 닫힘 | 둘 다 닫힘 |
|---|---|---|---|
| A, A′ | 0 | 1 | 2 |
| B, B′ | 0 | 3 | 6 |
| C, C′ | 0 | 9 | 18 |

   "특정한 총 슬라이드가 필요하면 6개 릴레이 중 일부를 골라 여자시켜 그 합을 얻을 수 있다"(튜링 보고서 인용). 0–25의 모든 값이 만들어진다(최대 26).
7. **정지하지 않고 기록.** 영국·해군 봄베는 일관된 위치에서 멈추지만, 육군 봄베는 **멈추지 않고 결과를 기록**하며 계속 진행한다.
8. **로터 선택.** 드럼을 갈아 끼우지 않고 제어반에서 선택한다.

**해석(이 노트의 추론, 출처에 없는 부분).**

- "비즈네르 슬라이드"는 순환 시프트다. 로터 위치 p에서의 치환은 `shift(−p) ∘ 고정배선 ∘ shift(+p)`이므로, 고정 배선 앞뒤에 가변 순환 시프트를 두면 로터 한 단이 된다. 6번 항은 이 시프트를 3단(±0/1/2, ±0/3/6, ±0/9/18)으로 구성했다는 뜻으로 읽힌다. PLAN.md 3절의 "고정 배선 + 앞뒤의 순환 시프트, 이진 단계(1·2·4·8·16)" 구상과 같은 원리이고 진법만 다르다.
- 6개 릴레이가 26선 전체를 전환하려면 릴레이 하나가 26선(양방향 전류를 따로 다루면 52선)을 전환해야 한다. 표준 전화 릴레이의 접점 수로는 부족하므로 실제로는 릴레이 여러 개를 묶었거나 다접점 릴레이를 썼을 것이다. M 유닛 하나가 3 m × 2 m 랙이라는 점이 이를 뒷받침한다. **접점 수·릴레이 수의 실제 값은 확인하지 못했다.**
- 위치 계수(26진 3자리)와 가운데·느린 로터의 진행을 어떤 회로로 했는지(릴레이 계수기인지 스테핑 스위치인지)는 출처에 없다.

### 3.3 장점과 확장

- 장점으로 든 것: 속도, 표준 전화 부품(정비·보안), 기계적 응력과 마모 없음, 조작 인원 감소, 로터 교체 30초, "디지털이라 더 정확" [@dturing2021army].
- 회전부가 없어 부착 장치만으로 기능을 넓힐 수 있었다 [@dturing2021army]:

| 부착 장치 | 시기 | 기능 |
|---|---|---|
| Machine-gun | 1943-10 | 정지의 체킹(메뉴 각 쌍의 스테커 모순 검사)을 자동화 |
| Double-input | 1943-10 | 메뉴 2개 동시 시험 |
| Dud-buster | 1944-10 | 로터·링·스테커는 알고 메시지 시작 위치만 모르는 전문("dud")의 위치 탐색 |
| Autoscritcher | 1944-12까지 | 가변 반사판(Umkehrwalze D)의 배선 탐색. 영국 Giant, 해군 Duenna와 같은 목적 |

- Friedman은 이 기계를 "범용 암호 기계"로 보았고, 종전 직후 144프레임 중 56개를 미군 자체 암호의 보안 시험용으로 돌리자고 제안했다 [@dturing2021army].

## 소프트웨어 모델에 대한 함의

1. **4로터 스크램블러.** 3로터 스크램블러 + (4번째 로터 ∘ 얇은 반사판)으로 구성한다. 4번째 로터는 구간 내내 고정이므로 "(Beta/Gamma 위치 26) × (얇은 B/C) → 등가 반사판"을 미리 계산해 3로터 코어를 그대로 재사용할 수 있다. Beta@A + 얇은 B = 반사판 B, Gamma@A + 얇은 C = 반사판 C라는 항등식을 단위 시험으로 둔다.
2. **정지 조건은 3로터와 동일.** 미 해군형의 cold point test는 "입력 노드 26선이 전부 통전되지는 않음"이다. 코어의 정지 판정 함수를 공유한다.
3. **hot point test = 자동 체킹.** 미 해군형은 정지마다 스테커를 유도해 모순이 있으면 기각하고 통과한 것만 내보낸다. `check` 모듈을 구동 루프 안에서 호출하는 "자동 기각" 모드로 재현한다. 시험 기준: 13글자 크립 사례에서 정지 188회 중 1회 통과 [@ekhall-hallenberg2018] 정도의 기각률.
4. **모델 구분은 설정값으로.** 유닛 수(36 / 16), 뱅크 수(3 / 1), 동시 입력 수(chain 4 / PRI·SEC 2), 자동 검사 유무, 출력 형식(지시 드럼 글자 / 숫자 인쇄)을 기종 설정으로 분리한다. 전파 엔진은 같다.
5. **탐색 순서와 속도.** 4휠 탐색에서 어느 휠이 가장 빠른지는 출처가 엇갈린다(1.4절). 정지 집합에는 영향이 없으므로 순서는 매개변수로 두고 기본값을 문서에 "미확정"으로 적는다.
6. **미 해군형 기준 모델 채택 여부(PLAN 6절 미결 사항).** 영국 4휠기는 3휠 봄베에 4번째 휠을 덧붙인 것이라 소프트웨어로는 "36유닛 + 4번째 휠"로 쉽게 표현되지만, 속도·감지 방식의 자료가 부족하다. 자료가 충분한 것은 미 해군형이다.
7. **릴레이 트랙(R 트랙) 설계 근거.**
   - 로터 한 단 = `시프트(+p) → 고정 배선 → 시프트(−p)`. 미 육군 봄베가 같은 분해(3진 3단: 1·3·9 단위, 단마다 0/1/2배)를 썼다는 2차 자료가 있다. PLAN의 이진 5단(1·2·4·8·16)과 접점 수를 비교해 고를 수 있다: 3진은 단 수 3, 단마다 3위치 선택(릴레이 2개), 이진은 단 수 5, 단마다 2위치 선택(릴레이 1개).
   - 소프트웨어 코어에 "시프트-배선-시프트" 형태의 스크램블러 구현을 하나 더 두고 표 조회 구현과 17,576위치 전부에서 일치하는지 시험하면, 그 구현이 RTL과 릴레이 회로의 직접적인 기준 모델이 된다.
   - 미 육군 봄베는 **펄스 구동**이다: 한 펄스가 시험과 다음 위치로의 전환을 함께 일으킨다. 릴레이 트랙의 타이밍 설계(시험 구간과 전환 구간의 분리)와 RTL의 동기식 구조(PLAN Phase 2)에 대응한다.
   - "정지하지 않고 기록"하는 방식은 릴레이·RTL 구현에서 정지·재시작 제어를 없애 준다. 소프트웨어의 `run()`이 정지 목록을 반환하는 형태와 같다.
8. **해군형의 접점 단락 설계.** 미 해군형은 브러시가 인접 세그먼트를 단락시키며 넘어가므로 전환 중에는 26선이 모두 통전된 것처럼 보여 정지가 나지 않는다. 기어식 실물에서 회로 차단기(영국식)와 단락 브러시(미국식) 중 하나를 고를 때의 근거가 된다. 소프트웨어 모델에는 영향 없음.
